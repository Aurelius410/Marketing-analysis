# 資料特徵檢驗（M2／M4）

這份文件管的是整條產線上**唯一會發出「禁行令」的關卡**。M1 資料體檢告訴你資料長什麼樣，M2／M4 告訴你「這批資料**可不可以**餵給下游那個方法」——兩件事完全不同，混在一起做是包子過去最常出的結構性錯誤。

漏掉這關的代價不是報告不夠漂亮，而是**每一個下游數字都在錯誤的前提上算出來的，而且不會報錯**。三個具體後果：客單價偏度 4.2 沒檢驗就丟進 ANOVA，F 檢定的 p 值整組失真，事後檢定（E1 那條命）跑出來的分組是假的；RFM 三欄尺度差 1000 倍沒標準化就跑 k-means，分出來的四群其實只是「按金額切四段」，你卻拿它去寫行為分群的策略建議；VIF = 43 的兩個廣告變數沒攔下來，係數符號翻轉，報告寫成「電視投放對營收有負向影響，建議砍電視預算」。這三個錯誤都不會有任何 exception，只會產出看起來完全正常的表格。

## 一、十項檢驗：每一項各自決定什麼

### 1.0 總覽

「檢定方法 → 判準門檻 → 下游通行證」是這一節每一小節的固定三段式。**沒有第三段的檢驗不要做**——跑了一個檢定卻不知道它擋掉什麼，那是 EDA 不是特徵檢驗。

| # | 檢驗項 | 主要方法 | 核心判準 | 決定什麼 | M4 複檢 |
|---:|---|---|---|---|:--:|
| 1 | 分布形態 | 偏度／峰度、Shapiro-Wilk、Anderson-Darling、Q-Q | \|skew\| < 1 | 要不要轉換、轉哪一種 | ✅ 門檻① |
| 2 | 變異數同質 | Levene（穩健）／Bartlett／Hartley | p > 0.05 | ANOVA 能不能用、要不要 Welch | ✅ 門檻② |
| 3 | 獨立性 | Durbin-Watson、ACF、ICC | DW ∈ [1.5, 2.5]；ICC < 0.05 | 要不要混合效果／時間序列 | 結構未變則免 |
| 4 | 多重共線性 | VIF、條件數 κ | VIF < 10（嚴管產業 < 5） | 係數能不能解讀 | ✅ 轉換會改變 |
| 5 | 尺度差異 | std 比值、全距比值 | max/min(std) < 10 | 距離型方法要不要標準化 | ✅ |

| 7 | 稀疏度與零膨脹 | 零佔比、過度離散 $\hat\psi$ | 零 > 30%；$\hat\psi$ > 1 | ZINB／Hurdle／Tweedie | 轉換後零仍在則免 |
| 8 | 類別基數 | distinct 數、各類 n | 任一類 n < 5 需合併 | 編碼方式與模型族 | 免（M3 不動類別） |

### 1.1 分布形態 → 決定要不要轉換

$$g_1=\frac{\frac1n\sum_{i=1}^n(x_i-\bar x)^3}{\left[\frac1n\sum_{i=1}^n(x_i-\bar x)^2\right]^{3/2}},\qquad g_2=\frac{\frac1n\sum_{i=1}^n(x_i-\bar x)^4}{\left[\frac1n\sum_{i=1}^n(x_i-\bar x)^2\right]^{2}}-3$$

$g_2$ 是**超額峰度**（excess kurtosis，常態 = 0）。`scipy.stats.kurtosis()` 預設 `fisher=True` 回傳超額峰度，R 的 `fBasics::kurtosis()` 預設也是超額——但 SPSS 與部分教科書回傳原始峰度（常態 = 3）。**總表裡一律標明用的是哪一種**，否則 M4 對照表會出現「峰度從 3.1 降到 0.1」這種其實沒變的假改善。

| 統計量 | 門檻 | 判定 | 門檻怎麼來的 |
|---|---|---|---|
| \|skew\| < 0.5 | — | 近似對稱，通行 | Bulmer (1979) 的三段式經驗分界，統計教科書通用 |
| 0.5 ≤ \|skew\| < 1 | — | 中度偏態，**登記但不強制轉換** | 同上 |
| \|skew\| ≥ 1 | 觸發 | 高度偏態，**必須轉換** | 同上；且 SKILL.md 把 \|skew\| < 1 訂為 M4 硬門檻 |
| 超額峰度 > 3 | 觸發 | 重尾，t 檢定的 α 會偏離名目值 | 重尾對均值型檢定的影響遠大於偏態，需搭配穩健方法 |
| Shapiro-Wilk p < 0.05 | 參考 | 拒絕常態 | 3 ≤ n ≤ 5000 有效 |
| Anderson-Darling A² > 臨界值 | 參考 | 拒絕常態，對尾部更敏感 | n > 5000 時取代 Shapiro |

**兩個必須知道的陷阱**：

1. **n > 5000 時 `scipy.stats.shapiro` 的 p 值不可靠**（SciPy 官方明示 N > 5000 的 p 值不準）。改用 Anderson-Darling。
2. **n 很大時常態檢定必然拒絕**。n = 50,000 的交易資料，偏度 0.05 也會被 Shapiro 判 p < 0.001。這時候 p 值沒有資訊量，**判定要改看效果量（偏度／峰度本身）與 Q-Q plot**，不是看 p。這也是為什麼 M4 的門檻① 訂在偏度而不是 Shapiro p 值。

行銷情境的實測：3C 賣場交易檔的 `Amount`（來源：`gdrive/own/03_新資料集剖析_3C與超市.md` §2.4.1）min = 0、q25 = 129、median = 399、mean = 1,575.80、q75 = 999、max = 69,500、std = 4,400.61。mean / median = 3.95，這是教科書級的右偏。**沒轉換就把 `Amount` 當 ANOVA 的反應變數比較五個品類的平均客單價**，F 檢定會被那批筆電訂單主宰，你會得到「p < 0.001，五個品類客單價有顯著差異」，然後照著做出「加碼推廣手機配件品類」的建議——實際上差異全部來自 7.2% 的高單價列。

| 訊號 | 轉換 | 出處 |
|---|---|---|
| 右偏嚴重（EDA hist / 箱型圖） | $\ln(Y)$ | MBA5045 1007／1014 |
| 各組平均越大、變異越大（扇形） | $\sqrt{Y}$ | MBA5045 1014 §11.3 |
| 資料含 0 需取 log | $\ln(x+\epsilon)$，`log(x + 1e-3)` | MBA5045 0930 實戰腳本 |
| 含負值（如淨額扣退貨） | Yeo-Johnson（Box-Cox 要求正值） | 教材未涵蓋，本 skill 補 |

### 1.2 變異數同質 → 決定 ANOVA 能不能用、要不要 Welch

三種檢定的分工來自 MBA5045「變異數分析」講義 §10.10，**選擇規則是硬的，不是偏好**：

| 檢定 | 前提 | 統計量 | 用時機 |
|---|---|---|---|
| **Modified Levene** | 無（對偏離常態穩健） | 先算 $D_{ij}=\lvert Y_{ij}-\tilde Y_{i}\rvert$（$\tilde Y_i$ 為組中位數），再對 $D$ 跑 one-way ANOVA | **實務首選**，行銷資料預設用這個 |
| **Bartlett** | 各組服從常態，樣本數可不同 | $\chi^2=2.3026\,q/c \sim \chi^2(k-1)$ | 已確認常態時，檢定力較高 |
| **Hartley** | 各組常態**且樣本數相同** | $H=\dfrac{\max S_i^2}{\min S_i^2}$ | 樣本數相同、要手算時 |

> 教材原文：「Bartlett 檢定與 Hartley 檢定，都相當依賴母體常態假設，而修正 Levene 檢定則對於母體偏離常態分配的狀況下，仍有相當好的檢定力。」（MBA5045「變異數分析」§10.10）

Python 實作：`scipy.stats.levene(*groups, center='median')`——**`center` 必須明寫 `'median'`**，SciPy 預設就是 median 沒錯，但寫出來是為了讓 code review 的人知道你用的是 Modified Levene 而非原始 Levene（原始版 center='mean'，對偏態不穩健）。

| Levene p | 判定 | 下游通行證 |
|---|---|---|
| p > 0.05 | 同質 | ✅ 標準 one-way ANOVA + Tukey HSD |
| 0.01 < p ≤ 0.05 且最大/最小組變異數比 < 4 | 邊緣 | ⚠️ ANOVA 可用但**改用 Welch**，事後檢定改 Games-Howell |
| p ≤ 0.01 或變異數比 ≥ 4 | 不同質 | ❌ 標準 ANOVA 禁行。Welch ANOVA，或轉換後重檢 |
| 各組 n 差異 > 3 倍 且 不同質 | 最壞情況 | ❌ 標準 ANOVA 禁行（型一誤差嚴重失真）。**先轉換後重檢；仍不同質就 Welch ANOVA + Games-Howell**（對 n 不等＋變異數不等最穩健）。**這一格不可以退到 Kruskal-Wallis**，理由見下 |

**變異數比 4 這條線的理由**：ANOVA 對變異數不齊的穩健性在「各組 n 相等」時很好，但 n 不等時，大變異數配小 n 會讓實際 α 膨脹到名目值的 2–3 倍。4 倍是實務上普遍採用的容忍上限。分群後跑組間比較最容易踩到——群大小天生不等。

**為什麼最壞情況不能退到 Kruskal-Wallis**：KW 拿掉了常態假設，卻**多了一個「各組分布形狀相同」的假設**——在變異數不等＋n 不等時（正是觸發這一格的條件），它檢定的是「分布有沒有差」而不是「位置有沒有差」，型一誤差跟著膨脹。這是 Behrens–Fisher 問題的秩版本，所以退到 KW 是往假設更強的方向橫移，違反 00 §1.6「只准往前提更少的方向退一格」。實測（20,000 次模擬，常態、各組平均數相同、n = 150/100/47、變異數比 11.4、名目 α = 0.05）：標準 ANOVA 實際 α = **0.223**、KW = **0.116**、Welch ANOVA = **0.049**。KW 只把 ANOVA 的膨脹砍一半，Welch 才回到名目值。〔實測 2026-07-27〕

連帶地，**「只能主張中位數排序」這句在這一格也不能寫**：KW 要能被讀成中位數比較，前提是各組形狀相近，而變異數比 11.4 時這個前提已經破了。同一組設定改成三組中位數**完全相同**、σ = 0.5/0.5/1.2 的對數常態，KW 仍有 **9.7%** 的機率拒絕虛無——拒絕的來源是離散度不是位置；先取 log 再跑 Welch 則回到 **5.0%**（這也說明這一格為什麼把「轉換」列在第一順位）。

所以 KW 的觸發條件統一寫成：**常態不成立且轉換無效，且各組變異數比 < 4**（與 `16_統計推論紀律.md` §8.4 的決策樹一致）；用了 KW 就必須附並排箱型圖確認各組形狀相近，否則結論只能寫「各組分布有差異」，不可寫成中位數排序。

**這一項不通過不等於不做 ANOVA**。18-E1 的規則是「ANOVA → 事後檢定綁定，不可分離，跑不出來要降級並說明，不准留空」。變異數不同質時的正解是**降級成 Welch**，不是跳過這一章。另外，跑 type-III ANOVA 一律走 `scripts/stats_utils.py` 的 `anova3()`，不要直接呼叫 `anova_lm(typ=3)`（見 18-T3，實測會靜默算出錯誤的主效果 SS）。

### 1.3 獨立性 → 決定要不要混合效果或時間序列

行銷資料的獨立性違反有兩種完全不同的來源，檢定方法也不同：

**（a）時間自相關**——日銷售、週流量這類序列。

$$DW=\frac{\sum_{t=2}^{n}(e_t-e_{t-1})^2}{\sum_{t=1}^{n}e_t^2},\qquad DW\approx 2(1-\hat\rho_1)$$

| DW | 判定 | 下游 |
|---|---|---|
| 1.5 ≤ DW ≤ 2.5 | 無明顯自相關 | ✅ OLS 可用 |
| DW < 1.5 | 正自相關（最常見） | ❌ OLS 標準誤低估 → 假顯著。改 Newey-West SE 或 ARIMA／狀態空間 |
| DW > 2.5 | 負自相關 | ❌ 通常代表模型設定錯誤（過度差分） |

搭配 ACF 圖看落後幾期。DW 只測 lag-1，週資料的 7 期週期性它抓不到。**MBA5045 只把 Durbin-Watson 列為「可能的解決方式」，沒有給公式與實作**（該 digest §14 第 10 條自承），上表的門檻是本 skill 補的通用經驗值。

**（b）同顧客多筆的組內相關**——這才是行銷資料的主要威脅。同一位顧客的 10 筆交易不是 10 個獨立觀測。

$$\rho_{ICC}=\frac{\sigma_b^2}{\sigma_b^2+\sigma_w^2},\qquad \mathrm{DEFF}=1+(\bar m-1)\,\rho_{ICC},\qquad n_{\text{eff}}=\frac{n}{\mathrm{DEFF}}$$

| ICC | 判定 | 下游 |
|---|---|---|
| < 0.05 | 可忽略 | ✅ 一般迴歸／檢定 |
| 0.05 – 0.20 | 需處理 | ⚠️ 群集穩健標準誤（cluster-robust SE），以 `cust_id` 分群 |
| > 0.20 | 嚴重 | ❌ 必須混合效果模型（隨機截距），或把分析單位聚合到顧客層 |

具體代價：3C 賣場 3,077 筆交易 ÷ 200 位顧客 = 每人平均 15.4 筆。若 ICC = 0.15，DEFF = 1 + 14.4 × 0.15 = 3.16，**有效樣本數從 3,077 掉到 974**。信賴區間寬度差 $\sqrt{3.16}\approx1.78$ 倍。在交易層跑「男女客單價差異」的 t 檢定會得到 p = 0.003，聚合到顧客層跑會得到 p = 0.09——前者讓你做出「針對男性客群加碼高單價品」的預算決策，後者告訴你這個差異看不出來。

這一項也是 18-G3（cohort 未對齊）的前哨：`tenure_days` 沒進模型時，老客的多筆交易會同時貢獻自相關與 cohort 偏誤。

### 1.4 多重共線性 → 決定係數能不能解讀

$$\mathrm{VIF}_j=\frac{1}{1-R_j^2},\qquad \mathrm{Tolerance}_j=1-R_j^2,\qquad \kappa=\sqrt{\frac{\lambda_{\max}}{\lambda_{\min}}}$$

| 指標 | 門檻 | 判定 | 出處 |
|---|---|---|---|
| VIF | > 10 | 高度共線 | MBA5045 1007 §9.6 |
| VIF | > 5 | 高度共線（**嚴管產業：電力／通訊／金融**） | 同上，教材明列 |
| VIF | = ∞ 或 > 1000 | **不是共線性，是欄位重複或 dummy trap** | 回 M1 查，不要當共線處理 |
| 條件數 κ | > 30 | 病態設計矩陣 | Belsley-Kuh-Welsch，教材未涵蓋，本 skill 補 |

**VIF 高 ≠ 模型不可用**。教材對這點有明確立場：「$\mathrm{VIF}$ 僅是告知此模型的解釋變數間具有高度線性相關的問題，但不代表此模型就不能使用，不應據此就推翻該模型。」（MBA5045 1007 §9.6）所以這一項發的是**有條件通行證**：

| VIF | 預測用途 | 係數解讀用途 |
|---|---|---|
| < 5 | ✅ | ✅ |
| 5 – 10 | ✅ | ⚠️ 標準誤已膨脹 $\sqrt{\mathrm{VIF}}$ 倍，報告須註明 |
| > 10 | ✅ **預測不受影響** | ❌ **禁止解讀個別係數的大小與符號** |

行銷情境的典型失效：電視 GRP 與數位曝光同期投放，VIF = 43。模型跑出電視係數 −0.8（p = 0.31）、數位 +2.1（p = 0.28），兩個都不顯著。錯誤行動是「兩個都不顯著，砍掉電視預算」；正解是「這兩個變數在這批資料裡分不開，要嘛合成投放強度指標，要嘛做地理實驗把它們拆開」。共線性的處理階梯（MBA5045 0923 §13.5）：補資料 → 合成變數 → 轉換 → 移除其一 → 標準化（僅對多項式／交互項有效）。

計算共線性用的相關矩陣要設**最低共現次數 n ≥ 5**（見 18-E10）。在稀疏二元矩陣上算 Pearson，兩個商品恰好被同一人買過就得 r = 1，VIF 直接爆炸，那不是共線性是樣本不足。

### 1.5 尺度差異 → 決定距離型方法要不要標準化

判準很簡單：

$$\text{尺度比} = \frac{\max_j \mathrm{sd}(x_j)}{\min_j \mathrm{sd}(x_j)}$$

| 尺度比 | 判定 | 下游 |
|---|---|---|
| < 3 | 可忽略 | ✅ 距離型方法可直接用 |
| 3 – 10 | 建議標準化 | ⚠️ 登記，由方法族自行處理 |
| > 10 | **必須標準化** | ❌ 未標準化的 k-means／KNN／HAC 一律禁行 |

**這一項是教材完全零覆蓋的地方**。大數據與商業分析 digest §15 明列：「標準化／尺度處理：**完全沒有提及**。教材沒有講『跑 K-means 前要不要 z-score / min-max』……這是行銷分群最常見的踩雷點（RFM 的 M 尺度遠大於 F），教材零覆蓋，Skill 必須自己加。」上表的門檻是本 skill 訂的。

具體算一次：3C 資料的 `Amount` std = 4,400.61、`Quantity` std ≈ 0.72（值域 1–21，mean 1.15）。尺度比 ≈ 6,112。歐氏距離裡 $\Delta M^2$ 對 $\Delta F^2$ 的貢獻比是 6,112² ≈ 3,700 萬比 1。**k = 4 的 k-means 跑出來的四群，本質上就是把金額由小到大切四段**，F 與 R 完全沒有進入分群。錯誤行動：把這四群當成行為分群，寫出「群 2 是中頻中額的穩定客，建議用會員日回饋維繫」——但群 2 裡面同時有「一年買一次筆電」和「每週買一次配件」的人，這兩種人的維繫策略完全相反。

**注意分工**：SKILL.md 明訂「標準化不在 M3 做，它屬於各方法族自己的第一步」。所以 M2 這一項**只登記不執行**，總表寫的是「距離型方法：需標準化」，實際的 `StandardScaler` 由 M6 分群腳本自己呼叫。這樣做的理由是標準化必須在 train/test 切分後、在 fold 內做，放進 M3 會製造洩漏（見 18-G4）。

### 1.6 離群結構 → 決定刪除 vs 分開建模 vs 穩健方法

**這一項的關鍵不是「有沒有離群」，是「離群是單點還是次族群」。** 兩者的處置完全相反，判錯的代價是把最有價值的顧客砍掉。

```
發現超出 1.5×IQR 或 |z| > 3 的點
        │
        ├─ 離群點數 / n < 1%  且  在各維度上分散無結構
        │        └→ 【單點】查 MBA5045 的四類成因 → 多半是輸入錯誤 → 更正或標記
        │
        ├─ 離群點數 / n ≥ 5%  或  在密度圖上形成第二個峰
        │        └→ 【次族群】不是離群，是另一個母體 → 分開建模，不准刪
        │
        └─ 1% ~ 5% 之間，或無法判斷
                 └→ 【存疑】做敏感度分析：刪掉重估，看係數/SE/R² 是否實質改變
                     ├─ 有實質改變 → 當次族群處理
                     └─ 無實質改變 → 紀錄即可，保留（教材原則）
```

判斷「次族群」的量化工具：對該欄跑核密度估計看是否雙峰；多維情形用 Mahalanobis 距離配 $\chi^2_p$ 的 0.975 分位數當門檻。

離群成因的四分類（MBA5045 0923 §4.5，教材原文）：

| 成因 | 處方 |
|---|---|
| 資料輸入錯誤（**最常見**） | 更正後重跑分析 |
| 重要變數遺漏 | 找回可能有用的變數納入後重估 |
| 迴歸假設失真（異質變異、非常態、交互項未檢驗） | 變數轉換、加入交互或非線性項，再重新評估 |
| **族群本質差異（潛在次族群）** | 疑似離群樣本獨立處理，其餘資料單獨重估，**分開分析** |

兩個真實例子，處置完全不同：

- **3C 客戶檔的 `Age` 有 1 歲與 108 歲**（來源：`03_新資料集剖析` §2.2）。n = 200 中僅 2 筆，分散無結構 → 單點、輸入錯誤。但該 digest §2.2 特別註記：「**建議做年齡分層時把 <15 與 >90 標為『未知』，不要直接刪列**（會損失交易金額）。」刪列 = 連同該客戶的所有交易一起消失，M 的總和對不上帳。
- **3C 前 3 名品類（筆電／LCD／數位相機）貢獻 61.75% 金額但只佔 7.2% 的列數**（同 digest §2.4.3）。這不是離群，是「高單價低頻」的結構。**對 `Amount` 做 winsorize(99%) 會把這批訂單全部壓平，總營收憑空少掉三成，而且不會有任何錯誤訊息。**

產表後要跑自動離群掃描：**同一欄內數量級差 > 100 倍即警告**（見 18-E9，學生K那份 ANOVA 表裡「61 歲以上」那格是 3217.258，同欄其他值都在 3.2~3.5 之間，A+ 報告也沒察覺）。

### 1.7 稀疏度與零膨脹 → 決定要不要 ZINB／Hurdle／Tweedie

| 指標 | 門檻 | 判定 | 下游 |
|---|---|---|---|
| 零佔比 | < 10% | 正常 | ✅ Poisson／一般迴歸 |
| 零佔比 | 10% – 30% | 過量零 | ⚠️ 先查過度離散，多半 NB 就夠 |
| 零佔比 | > 30% | 零膨脹 | ❌ Poisson 禁行。**先判斷零的來源** |
| 過度離散 $\hat\psi=\dfrac{\text{Residual Deviance}}{\mathrm{df}_{\text{residual}}}$ | > 1 | 有超額變異 | ❌ Poisson 的 SE 低估 → 假顯著；改 NB 或 quasi-Poisson |

$\hat\psi$ 的定義與「$\hat\psi>1$ ⇒ 有超額變異」出自 MBA5045 `03_quiz_analysis_workflow.md` 的檢查清單。該課另有一條順序鐵則（`02_logistic_glm_categorical.md` §3.8）：**Deviance 太大時，依序查（1）漏變數／非線性 →（2）少數幾筆殘差 > 2 撐大整體 →（3）都排除後才歸因 overdispersion。順序不能顛倒。**

零的來源決定模型族，這一步比選模型重要：

| 零的來源 | 例子 | 處置 |
|---|---|---|
| **結構零**（這個人根本不可能買） | 未開通該服務的會員，該品類購買次數必為 0 | 從母體排除，不要建模 |
| **抽樣零**（可能買但這期沒買） | 活躍會員本月未購買 | Hurdle（兩段：買不買 × 買多少） |
| **混合** | 兩者都有且分不開 | ZINB（零膨脹負二項） |
| **連續型的零＋右偏正值** | 顧客期間內消費金額 | **Tweedie**（複合 Poisson-Gamma），保險與行銷 CLV 的標準做法 |

真實案例：3C 交易檔 `Amount = 0` 共 242 筆（7.9%），集中在「會員補卡」等三個非商品品類；`會員補卡` 觸及 106/200 = 53% 的客戶（滲透率第 1）但總金額只有 780 元（來源：`03_新資料集剖析` §2.4.2）。**這是結構零，不是零膨脹。** 錯誤行動是套 ZINB 建模「客單價為零的機率」，然後得出「會員補卡是最強的交叉銷售入口，建議在補卡流程加推薦」——實際上補卡只是行政動作，它的高滲透率是分母污染。正解是把三個非商品品類從交易事實表排除再算指標。

### 1.8 類別基數 → 決定編碼方式與模型族

| distinct 數 $k$ | 編碼 | 條件 |
|---|---|---|
| $k=1$ | **剔除** | 零變異欄，任何模型都用不到 |
| $2 \le k \le 10$ | One-hot（$k-1$ 個 dummy） | 需指定參考組，避免 dummy trap |
| $10 < k \le 50$ | One-hot ＋ 長尾合併 | 任一類 $n < 5$ → 併入「其他」 |
| $k > 50$ | Target encoding（**必須 out-of-fold**）或 embedding | 非 out-of-fold 就是目標洩漏（18-G4） |
| $k > n/10$ | **禁行** | 類別數逼近樣本數，等於給每列一個 ID |

**卡方分析的額外門檻**：期望次數 ≥ 5 的格子要佔 80% 以上，且沒有任何格子期望次數 < 1（Cochran 規則）。不滿足就合併類別或改用 Fisher 精確檢定。**這一條直接關係到 18-E17**（所有群 × 所有人口變數都要出現在表中）——類別太細會讓一半的格子期望次數不足，表出得來但每一格都不可解讀。

真實基數（`03_新資料集剖析`）：3C `Category` 30 類 / 200 客戶；超市品項階層 98；**超市 L4 細類 297 類，該 digest 直接判「太稀疏，且無中文名稱」**。297 類配 200 位客戶，平均每類 0.67 位——拿去做因素分析或卡方都是空的。

呼應 18-E2 與 18-E12：人口統計變數（性別／婚姻／區域）就算基數很低、編碼很乾淨，**也不准進分群輸入白名單**，只能出現在卡方那一章；因素分析要在**品類層級（15–16 類）**，不是 SKU 層級。基數檢驗要在總表裡明確標出每個類別欄的「允許用途」，不要只標編碼方式。

### 1.9 樣本量對維度（n/p） → 決定能不能跑複雜模型

| 方法 | 判準 | 不滿足的後果 |
|---|---|---|
| 多元迴歸 | $n/p \ge 10$（保守 20） | 過度配適，Adjusted $R^2$ 與樣本外落差大 |
| Logistic 迴歸 | **EPV ≥ 10**（少數類事件數 ÷ 參數個數） | 係數偏誤、SE 爆炸（Peduzzi et al., 1996） |
| 因素分析 | 每變數 ≥ 5–10 個樣本，且 $n \ge 100$ | KMO 偏低、RMSEA 爆表 |
| ANOVA 每組 | $n_i \ge 20$（最低 10） | 常態與同質性檢定都沒有檢定力 |
| 分群 | 每群目標人數 ≥ 30 | 群內統計量不可解讀 |

**這一項最有價值的用途是事前否決。** 3C 資料 200 位客戶 × 30 個品類 → n/p = 6.7，低於因素分析的 10:1 底線。這正好解釋了 18-E11 那個案例：學生H的因素分析 RMSEA = 0.218（遠超 0.08 的可接受上限），她誠實揭露並改用相關係數，做法對。**如果在 M2 就跑過 n/p 檢驗，這個結果是可以事前預測的**——不是分析失敗，是樣本量本來就不支援這個方法。報告的正確寫法不是「因素分析適配不佳」，是「本資料集 200 位客戶對 30 個品類，n/p = 6.7，不支援因素分析；改以相關結構呈現」。

同時要接住 18-E22（樣本數變化未交代）：n/p 檢驗要用**最終建模樣本數**，不是原始列數。3C 有 186 筆完整重複列、超市有 364 筆，去重後 n 會變。總表的 `n_valid` 欄就是拿來給報告寫「原始 3,077 筆 → 建模 2,891 筆」的。

另外補 18-G/S 系列沒完全覆蓋的一條：**n/p 過關不代表「不顯著」可以解讀成「沒差異」**。`gap-statistical-inference.md` S12 的實例：$n_1=21$、$n_2=12$、SD ≈ 3,000 元時，power = 0.8 的 MDE 約 2,500 元——**即使兩群真實差異有 2,500 元（約 40% 的客單價落差），這個樣本也大概率看不出來**。M2 的 n/p 檢驗要一併輸出各組 MDE，讓 M11 知道哪些「無顯著差異」其實是「看不出來」。

### 1.10 目標變數平衡度 → 決定 class weight 與評估指標

| 少數類佔比 | 少數類絕對數 | 處置 | 主要評估指標 |
|---|---|---|---|
| ≥ 20% | — | 不處理 | ROC-AUC、Accuracy 可用 |
| 5% – 20% | ≥ 100 | `class_weight='balanced'` | **PR-AUC**、F1 |
| 1% – 5% | ≥ 100 | class weight ＋ 閾值調校 | **PR-AUC、Top-N Lift**，門檻不准用 0.5 |
| < 1% | ≥ 100 | 改成排序問題 | **只報 Top-N Lift 與 Precision@N** |
| 任意 | **< 50** | ❌ **不建模**，改業務規則 | — |

**Accuracy 在不平衡時是廢的**，這在大數據與商業分析 §12.2 有直接的數字：類別 A 800 筆、類別 B 200 筆，「全部猜 A」的 Accuracy = 80%。同一份材料 §11 的 1% base rate 例子更狠：模型「準確率 99%」，被標記為「會轉換」的人裡也可能只有一半真的會轉換。該 digest 的評註寫得很清楚——「向老闆解釋『為什麼名單品質沒有 99%』時，直接用這一段」。

行銷的正例天生稀有：轉換率 1%、流失率 3%、詐騙率 0.1%。所以這一項幾乎每次都會觸發。**具體錯誤行動**：流失率 3% 的資料，跑完 XGBoost 用預設 0.5 閾值出名單，模型預測「會流失」的只有 11 人，其中 7 人真的流失。看起來 Precision = 64% 很漂亮，但**全體 3,000 名流失者你只撈到 7 個**（Recall = 0.23%）。挽回活動發出去 11 封信，主管問「所以我們的挽回計畫覆蓋了多少風險客戶」——答案是 0.23%。正解是把閾值降到讓名單量對上行銷團隊的執行量（例如 Top 500），然後報 Lift@500。

```python
# M2 目標平衡度檢驗的最小實作
minority_rate = y.mean() if y.mean() < 0.5 else 1 - y.mean()
minority_n    = int(min(y.sum(), len(y) - y.sum()))
verdict = ("BLOCK_模型不可建，改業務規則" if minority_n < 50
           else "PASS"       if minority_rate >= 0.20
           else "TRANSFORM_class_weight+PR_AUC")
# 一律連同 minority_n 寫進總表；只寫比例的話，n=40 的 4% 和 n=4000 的 4% 會長一樣
```

## 二、輸出：特徵檢驗總表

這張表是 M2／M4 的**唯一交付物**，也是 **M3 前處理程式的輸入**。人看的版本是寬表，但**存檔一律用長表**（一欄 × 一檢驗 = 一列），理由有二：新增檢驗項不用改 schema；寬表要靠 pivot 產生，而 DuckDB 在明細資料上 `PIVOT` 內部用 `list()`、大表必 OOM（見 18-T6），只在這種已聚合的小結果上 pivot 才安全。

| 欄名 | 型別 | 說明 |
|---|---|---|
| `run_id` | VARCHAR | `M2` 或 `M4`；M4 的每一列都要能對回 M2 的同一列 |
| `as_of_date` | DATE | 檢驗所用資料的切分日，防洩漏（18-G4） |
| `column_name` | VARCHAR | 欄位名 |
| `role` | VARCHAR | `feature` / `target` / `id` / `dimension` |
| `n_valid` | BIGINT | 該欄非空且進入檢驗的列數 |
| `test_id` | VARCHAR | `T1_dist` … `T10_balance`，對應 §一的十項 |
| `statistic` | DOUBLE | 檢定統計量或指標值（偏度、VIF、ICC…） |
| `p_value` | DOUBLE | 有 p 值才填，圖形判讀留 NULL |
| `threshold` | VARCHAR | 這次判定用的門檻（**寫死在表裡，不要只寫在程式**） |
| `verdict` | VARCHAR | `PASS` / `TRANSFORM` / `BLOCK` |
| `blocked_methods` | VARCHAR | verdict = BLOCK 時必填，寫**禁行的下游方法**，不是理由 |
| `suggested_action` | VARCHAR | verdict = TRANSFORM 時必填，指定轉換與順位（給 M3 讀） |
| `evidence` | VARCHAR | 圖檔路徑或降級說明（見 §六） |

三種判定的定義是硬的：

| verdict | 意思 | M3 要做什麼 | 報告要寫什麼 |
|---|---|---|---|
| `PASS` | 這一欄在這一項上滿足下游前提 | 不動 | 不用寫 |
| `TRANSFORM` | 不滿足，但已知轉換能救 | 照 `suggested_action` 做，M4 複檢 | 寫轉換與理由（第幾順位、前面的為什麼不行） |
| `BLOCK` | 不滿足，且轉換救不了 | 不動 | **必寫**：這一欄禁止進哪些方法，以及替代方案 |

`BLOCK` 不是「這欄不能用」，是「這欄不能進**某些**方法」。VIF = 43 的欄位可以進預測模型，只是不准解讀係數。**blocked_methods 寫得越具體，M3 與 M7 才越不會誤刪有用的欄位。**

```sql
-- M2 產出的總表存成 parquet，M3 直接讀它決定要做哪些轉換
COPY (
  SELECT * FROM feature_check_log WHERE run_id = 'M2'
) TO '04_features/feature_check_M2.parquet' (FORMAT parquet, COMPRESSION zstd);

-- 給人看的寬表（已聚合，pivot 安全）
PIVOT (SELECT column_name, test_id, verdict FROM feature_check_log WHERE run_id = 'M2')
  ON test_id USING first(verdict) GROUP BY column_name;

-- M3 的入口查詢：只拿要轉換的
SELECT column_name, suggested_action
FROM   feature_check_log
WHERE  run_id = 'M2' AND verdict = 'TRANSFORM'
ORDER BY column_name;
```

報告裡引用的每一個檢驗數字，都必須從這張表產生，不准手打（見 18-E7：學生E那份圖例標「女 75.20%、男 24.80%」，內文卻寫成完全相反）。

## 三、M4 複檢的三個門檻

M4 是硬卡點。三個門檻**全過才發通行證**，任一不過要回 M3 換轉換，或明確降級並寫進報告。

| # | 門檻 | 判準 | 不過的處置 |
|---:|---|---|---|
| ① | 偏度 | 所有進入下游的連續欄 $\lvert\text{skew}\rvert < 1$ | 換轉換（順位見 ref 06）；仍不過改無母數或穩健方法 |
| ② | 變異數同質 | Levene p > 0.05；**或**已明確改用 Welch | 兩者都沒有 → ANOVA 章節禁行，降級並說明（18-E1） |
| ③ | **轉換前後排序相關** | Spearman $\rho_s > 0.95$ | **回退該轉換**，這一項不准降級 |

$$\rho_s = 1-\frac{6\sum_{i=1}^{n} d_i^2}{n(n^2-1)},\qquad d_i=\mathrm{rank}(x_i^{\text{原始}})-\mathrm{rank}(x_i^{\text{轉換後}})$$

### 3.1 為什麼第三個門檻是唯一的防線

前兩個門檻只看**邊際分布的長相**——偏度、峰度、常態檢定，全部是「這批數字攤平以後長什麼樣」。它們**完全看不到誰在前、誰在後**。

而下游全部靠順序吃飯：

- RFM 分數是按分位數切的 —— 順序決定誰是 5 分誰是 1 分
- 分群是按距離算的 —— 順序壞了，相對位置就壞了
- Lift、Top-N 名單、CLV 排名 —— 這三個交付物本質上**只有順序，沒有數值**

所以存在一種最危險的失敗模式：**前兩個門檻全綠，資料其實已經毀了。**

具體怎麼發生的，用真實數量級走一次。3C 的 `Amount`（median 399、mean 1,576、max 69,500、偏度約 4.2）要做轉換，M3 的腳本寫成「先 winsorize 再 log」——這已經違反 SKILL.md 的鐵則（預設先轉換再看還有沒有離群），而且 winsorize 的上界被誤設成 `quantile(0.50)` = 399 元：

| 檢驗 | 轉換前 | 轉換後 | 門檻 | 結果 |
|---|---:|---:|---|:--:|
| 偏度 | 4.21 | 0.28 | < 1 | ✅ 過 |
| Shapiro p | 0.000 | 0.412 | > 0.05 | ✅ 過 |
| **Spearman ρ** | — | **0.71** | > 0.95 | ❌ **擋下** |

發生了什麼：200 位顧客裡有 96 位的 `Amount` 被壓成同一個值 399。他們之間的**排序資訊被整片抹平**。但因為壓平會同時消滅偏態，前兩個指標反而變得非常漂亮。

如果沒有第三個門檻，這批資料會直接進 M6 分群。後果：**消費金額最高的 96 位顧客在特徵空間中彼此完全不可分辨**，k-means 會把他們隨機散進各群。你的 VIP 名單等於從高消費族群裡隨機抽樣，然後你拿著這份名單去發專屬禮遇，並在報告裡寫「經分群識別出的高價值客群」。

### 3.2 ρ 掉下來時該想什麼

**單調轉換的 Spearman 理論上是 1.0。** log、sqrt、Box-Cox（λ > 0）、Yeo-Johnson 全都是嚴格單調遞增，數學上不可能改變順序。所以：

> **ρ < 0.95 不代表「轉換太猛」，而是「這個轉換不是純單調的，有東西被偷偷改掉了」。**

四個可能的兇手，按出現頻率排：

| ρ 掉下來的原因 | 徵兆 | 處置 |
|---|---|---|
| **winsorize / clip 造成大量並列** | 轉換後值的 distinct 數暴跌 | 拉高上界，或改成先轉換再看離群 |
| **遺失值處理前後不一致** | 兩邊的 `n_valid` 不同 | 對齊索引後重算，ρ 一定要在同一批列上算 |
| **分段套不同轉換** | 轉換函數裡有 `if` | 禁止，改成單一單調函數 |
| **倒數轉換** $1/x$ | ρ ≈ −1.0（**負的**） | 倒數是單調**遞減**，會整個反轉。要嘛改用 $-1/x$，要嘛在總表明記方向已反轉 |

第四項特別要小心：MBA5045 0930 的實戰腳本用了 $Y = 1/\text{Usage}$ 這個轉換，在迴歸裡完全正確，但**如果那一欄之後要拿去做 RFM 分數或 Top-N 排名，方向反轉會讓最好的變成最差的**。ρ 取絕對值就看不出來了，所以**總表存的是有號的 ρ，不是 |ρ|**。

門檻訂在 0.95 而不是 1.0，是留給浮點誤差與 ties 的容忍空間（單調轉換配上少量重複值，Spearman 的 tie correction 會讓它掉到 0.99 左右）。**0.95 到 1.0 之間要在總表寫原因；低於 0.95 直接回退。**

```
1. ρ < 0.95                                → ❌ 回退，不看其他欄
2. ρ ≥ 0.95 且 |轉換後偏度| < 1            → ✅ 通過
```

## 六、檢定跑不出來時的降級

**降級不留空**（六條紀律第 6 條）。跑不出來要降級並說明，不准留白。降級本身不扣分，**不說明才扣分**。

| 情況 | 為什麼跑不出來 | 降級動作 | 總表怎麼填 |
|---|---|---|---|
| 每組 $n < 20$ | Levene 檢定力太低，p > 0.05 只代表看不出來 | 並排箱型圖 ＋ 列出各組 SD 與變異數比 | `p_value = NULL`，`evidence` 填圖檔路徑 |
| 每組 $n < 10$ | 箱型圖本身資訊不足 | 改 **strip plot**（教材原則：每組 n < 10 用條狀點圖） | 同上 |
| $n < 8$ | Shapiro-Wilk 幾乎必過（檢定力趨近 0） | 只看 Q-Q plot | `statistic` 填偏度，`p_value = NULL` |
| $n > 5000$ | Shapiro p 值不可靠 | Anderson-Darling ＋ Q-Q；**判定改看偏度** | `test_id` 標 `T1_dist_AD` |
| VIF = ∞ | 完全共線 → 有恆等欄或 dummy trap | **不是共線性問題，回 M1 查重複欄位** | `verdict = BLOCK`，`evidence` 填「疑似欄位重複」 |
| 某類別欄 $k=1$ | 零變異，任何檢定都無定義 | 直接剔除 | `verdict = BLOCK`，`blocked_methods = ALL` |
| 每位顧客只有 1 筆 | 沒有組內重複，ICC 無定義 | 以資料結構論證獨立性 | `evidence` 填「單筆結構，無組內相關」 |
| 分群後某群 $n = 47$ | 事後檢定檢定力不足 | 放寬 α 至 0.20 **並在表標題明寫**（18-E18） | `threshold` 欄寫 `alpha=0.20` |

降級的標準措辭，直接抄進報告：

```
【圖形判讀】
「本欄各組樣本數為 12 / 9 / 15，低於 Levene 檢定的建議下限，
  改以並排箱型圖與各組標準差判讀：三組 IQR 相近（SD 分別為
  1,204 / 1,318 / 1,150，最大/最小比 1.15 < 4），無明顯異質變異。
  以圖形判讀，未做正式檢定。」

【常態檢定在大樣本失效】
「本欄 n = 48,213，Shapiro-Wilk p < 0.001，但偏度僅 0.31、
  超額峰度 0.44。大樣本下常態檢定對微小偏離即拒絕，
  故判定以偏度為準：通過。Q-Q plot 見圖 3-4。」

【檢定力不足，不顯著 ≠ 沒差異】
「第 3 群 n = 47、第 5 群 n = 21，α = 0.05、power = 0.8 下的
  最小可偵測差異為 2,480 元。本次檢定不顯著（p = 0.31），
  正確解讀為『此樣本量看不出 2,480 元以內的差異』，
  而非『兩群客單價相同』。」
```

**降級一律往「資訊更少但更誠實」的方向走，不准往「換一個會顯著的檢定」的方向走。** 換檢定要在跑之前就決定，不能看到 p 值再換。

## 七、與統計課教材的對照（MBA5045）

這一節把 MBA5045 逐週講義的診斷順序與判讀規則整理進來，出處標到週次。**先講一個分工上的界線**：教材的診斷是**迴歸診斷**，多數指標（殘差圖、槓桿值、Cook's D）要**模型配適完成才算得出來**，所以它們屬於 M7（ref 08），不是 M2／M4。M2 能做的是「不需要模型的那些」——分布、變異數、尺度、基數。

**M2 的正確做法是跑一次「探路迴歸」**：以候選 Y 對候選 X 配一個最簡模型，只為了取得殘差來判斷同質變異與獨立性，不解讀任何係數。這個模型不寫進報告。

### 7.1 診斷順序（0923「實務上的快速流程」＋ 0923 R code 排列順序，交叉驗證一致）

```
Step 0  Global F test        模型整體有沒有訊號？                         [0916]
Step 1  殘差三圖（假設檢查）  必須先做，因為 Step 2 的判準依賴四大假設    [0909/0916]
        ├ Residual plot (fitted vs residual) → 零均值 / 同質變異 / 獨立性
        ├ Histogram of residuals             → 常態性
        └ Q-Q plot + qqline                  → 常態性（比 Histogram 敏感）
Step 2  Outliers（Y 方向）    rstandard()，|studentized residual| > 3      [0923]
Step 3  Leverage（X 方向）    hatvalues()，h > 3(k+1)/n                    [0923]
Step 4  Cook's distance       cooks.distance()，D ≥ 1 或 0.5 ≤ D < 1       [0923]
Step 5  共線性                pairs/cor → vif()，VIF > 10（嚴管產業 5）    [0923/1007]
Step 6  變數選擇              backward/forward/stepwise → AIC/Adj R² 收尾  [0923]
Step 7  敏感度分析            移除可疑點重估，看係數/SE/R² 是否實質改變    [0923]
```

**Step 1 一定在 Step 2–4 之前**：studentized residual 只有在四大假設成立下才近似 $\mathcal N(0,1)$，假設沒過，$|r| > 3$ 這條線本身就沒有意義。

### 7.2 殘差圖三種形狀各代表什麼（0909 / 0916 §4.1，教材原文）

| 圖上看到 | 違反的假設 | 為什麼 | 處方 |
|---|---|---|---|
| **漏斗形**（左窄右寬或相反） | 同質變異 | 誤差變異隨 $X$ 或 $\hat Y$ 改變 | **對數或平方根轉換**／WLS／robust SE |
| **弓形** | 同質變異 | 誤差隨 $X$ 改變而增減 | 同上 |
| **波浪狀／週期性** | 獨立性 | 誤差自我相關（常見於時間序列） | Durbin-Watson 檢查／Newey-West SE |
| **整體偏上或偏下** | 零均值 | 模型有系統性偏差 | 檢查是否漏了關鍵變數或截距設定 |
| 點雲上下對稱、寬度均勻、無模式 | — | 理想狀況 | ✅ |

行銷情境的翻譯：漏斗形＝「大客戶的預測誤差比小客戶大得多」，直接對 log(營收) 建模；波浪狀＝「同一檔期內的門市誤差連在一起」，那是 §1.3 的 ICC 問題，不是自相關。

### 7.3 影響點的三個門檻（0923 §4.5–4.7）

| 指標 | 判準 | 教材說明 |
|---|---|---|
| studentized residual | $\lvert r\rvert > 3$ | 兩尾機率約 < 0.002 |
| 槓桿值 $h$ | $h > \dfrac{3(k+1)}{n}$ → 需進一步檢查 | $k$ = 解釋變數個數，$n$ = 樣本數 |
| 槓桿值 $h$ | $h < \dfrac{2(k+1)}{n}$ → 該點很孤立，也需檢查 | **這條下界是這份筆記獨有的說法**，一般教科書只講上界；建議兩條線都畫 |
| 槓桿值 $h$ | $\dfrac{2(k+1)}{n}\le h\le \dfrac{3(k+1)}{n}$ | 暫無過度影響的明確證據 |
| Cook's D | $D \ge 1$ | 強警訊 |
| Cook's D | $0.5 \le D < 1$ | 留意 |
| Cook's D | $4/n$ | 0930 實戰腳本加的業界常用線；**三條都畫，但主判準用 1.0 / 0.5** |

> **教材原文的關鍵判讀原則**：「殘差大 ≠ 影響一定大；槓桿高 ≠ 影響一定大。**殘差大 + 槓桿高 = 最危險，但仍需視庫克距離而定。**」

槓桿門檻的實例（0923 投影片，HOMES4a：$k=5$、$n=148$）：$3(k+1)/n = 18/148 = 0.12$，$2(k+1)/n = 12/148 = 0.08$。教材同時示範了**移除高槓桿點後模型幾乎沒變**（$R^2$ 0.6808 → 0.6757，p 值皆 < 2.2e-16）——這正是「未顯著影響 → 紀錄即可，通常保留」的實證，不要看到高槓桿就刪。

## 九、維護條款

**什麼情況要更新這份文件：**

1. **新增一項檢驗**——必須同時給出「檢定方法 + 判準門檻 + 下游通行證」三段。只有前兩段的不要加進來，那是 EDA，屬於 ref 04。
