## 一、為什麼 $p<0.05$ 不能當唯一標準

### 1.1 p 值同時被兩件事決定，而其中一件與商業無關

兩獨立樣本均值差的 t 統計量：

$$t=\frac{\bar x_1-\bar x_2}{s_p\sqrt{\frac1{n_1}+\frac1{n_2}}},\qquad s_p=\sqrt{\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}}$$

分子是**商業上關心的差異**，分母隨 $\sqrt{n}$ 縮小。所以 $p$ 值是「效果大小」與「樣本量」的混合物，**單看 $p$ 無法還原出任何一個**。教材對這件事講得很直接：「效果大小與解讀要一併呈現（彈性、變化率、邊際效果），**不能只報 p-value**」【教材：MBA5045 `02_logistic_glm_categorical.md` Part 5 §5.5 E3】；卡方那一側更明白——「卡方本身並不負責描述『有多強』，只負責說『顯不顯著』」【教材：同上 E1】。

### 1.2 大樣本端：算給你看

交易明細 42 萬列，切成兩群各 21 萬列，客單價 SD = 1,200 元。標準誤：

$$SE=1{,}200\times\sqrt{\tfrac{1}{210{,}000}+\tfrac{1}{210{,}000}}=1{,}200\times0.003086=3.70\ \text{元}$$

$p<0.001$ 需要 $|t|>3.291$，換算成差異只要 **12.2 元**。實際差 13 元 → $t=3.51$、$p=0.00045$，效果量 Cohen's $d=13/1200=0.011$，是 Cohen 慣例「小效果」門檻 0.2 的 **1/18**【文獻：Cohen (1988)】。

**錯誤行動**：報告寫「群 A 客單價顯著高於群 B（$p<0.001$）」，建議對群 B（21 萬人）發滿額券拉客單價，人均成本 80 元。真實可拉的空間是 13 元，毛利率 30% → 每人回收 3.9 元，**淨虧 76.1 元 × 21 萬人 = 1,598 萬元**。這份報告的每一個數字都是對的。

### 1.3 小樣本端：算給你看

分群後群 3（$n=47$）與群 1（$n=200$）比客單價，SD = 3,000 元。$\alpha=0.05$ 雙尾、power = 0.8 的最小可偵測差異：

$$\text{MDE}=(z_{0.975}+z_{0.80})\cdot s\cdot\sqrt{\tfrac1{n_1}+\tfrac1{n_2}}=(1.96+0.84)\times3{,}000\times\sqrt{\tfrac1{47}+\tfrac1{200}}\approx 1{,}362\ \text{元}$$

真實差距 900 元 < MDE 1,362 元，這個樣本量**本來就檢定不出來**：實算 $SE=3{,}000\times\sqrt{1/47+1/200}=486.3$、$t=900/486.3=1.85$、$p=0.065$、95% CI $=[-58,\ 1{,}858]$。$p=0.065$ 的正確翻譯是「本樣本看不出 1,362 元以內的差異」，不是「兩群客單價相同」——注意它離 0.05 只差一點，四捨五入成「無差異」的代價尤其大。錯誤行動：兩群合併定價，放棄 $900\times47=42{,}300$ 元／期的價差機會，而且因為報告寫了「已檢定、無差異」，這個決定半年內沒有人會再質疑。

> MDE 的另一組數值範例（$n_1=21$、$n_2=12$、SD = 3,000 → MDE ≈ 3,010 元）見 `00_通則 §四`，該處已示範 `n.s.` 必附 MDE 的表格寫法，此處不重複。

### 1.4 升級：三者並報

**硬規則**：任何進入報告的組間比較，`p 值 + 效果量 + 信賴區間` 三欄缺一不可。差異的 CI：

$$(\bar x_1-\bar x_2)\ \pm\ t_{1-\alpha/2,\ \nu}\cdot s_p\sqrt{\tfrac1{n_1}+\tfrac1{n_2}}$$

這一改會讓表格最後一欄（18-E15 要求的中文結論欄）從「顯著／不顯著」變成「值不值得做」：

## 二、效果量的選擇與判讀

### 2.1 五種效果量，按資料型態選

| 情境 | 效果量 | 公式 | 小／中／大 | 出處 |
|---|---|---|---|---|
| 兩組均值 | Cohen's $d$ | $d=\dfrac{\bar x_1-\bar x_2}{s_p}$ | 0.2 / 0.5 / 0.8 | 【文獻：Cohen (1988)】 |
| 兩組均值、$n<20$ | Hedges' $g$ | $g=d\left(1-\dfrac{3}{4(n_1+n_2)-9}\right)$ | 同上 | 【文獻：Hedges (1981)】；`pg.pairwise_tukey` 直接給 `hedges` 欄【實測：`research/02` §A.8】 |
| ANOVA 整體 | $\eta^2$ | $\eta^2=\dfrac{SS_{between}}{SS_{total}}$ | 0.01 / 0.06 / 0.14 | 【文獻：Cohen (1988)】 |
| 多因子 ANOVA / ANCOVA | partial $\eta^2$ | $\eta_p^2=\dfrac{SS_{effect}}{SS_{effect}+SS_{error}}$ | 同上（但見 2.2） | `pg.anova(detailed=True)` 的 `np2` 欄【實測：`research/02` §A.8】 |
| 卡方（$r\times c$） | Cramér's $V$ | $V=\sqrt{\dfrac{\chi^2}{n\cdot\min(r-1,c-1)}}$ | <0.1 弱 / 0.1–0.3 中 / >0.3 強 | 【實測：IB5082 `04_期末報告樣本與報告文體.md` §4.8，學生 C（A+）報告實際使用的分級】 |
| logistic / 2×2 | odds ratio | $\widehat{OR}=\dfrac{a d}{b c}$ | 1.44 / 2.48 / 4.27 | 【文獻：Chinn (2000) 的 $d=\ln(OR)/1.81$ 換算，對應 $d$ = 0.2/0.5/0.8】 |
| 行銷通用 | lift % | $\text{lift}=\dfrac{\text{處理組}-\text{對照組}}{\text{對照組}}\times100\%$ | **沒有統計門檻**，見 2.3 | 【推導，待驗證】 |

### 2.2 三個必須知道的判讀陷阱

**(a) one-way 時 $\eta^2=\eta_p^2$，two-way 時不相等。** 多因子模型的 partial $\eta^2$ 各項**加總可以超過 1**，因為每一項的分母都不同。把它們當「解釋比例」加起來寫成「三個因子共解釋 118% 的變異」是嚴重誤讀。報告只寫一種，並在表註寫明是哪一種。

**(b) 卡方的 $\chi^2$ 值本身不是效果量。** $\chi^2$ 隨 $n$ 線性放大，Cramér's $V$ 才做了 $n$ 的標準化。學生 C 的 A+ 報告就是靠多加一欄 $V$ 把「不顯著」寫成有內容的結論【實測：IB5082 §4.8】。**沒有 $V$ 欄的卡方表不得交付。**

**(c) 極端組設計會膨脹效果量。** CAI 兩尾各取 10% 再比較人口變數，任何弱關聯都會看起來很強，而且後續期間必然出現向均值回歸（見 §七 P4）。這種差異**只能用來產名單，不可用來估計關聯強度**【實測：`research/gap-statistical-inference.md` S6 修補動作 4】。

### 2.3 行銷的實務門檻不是 Cohen，是損益兩平

統計上的「小效果」在行銷上可能非常值錢，反過來也成立。真正的門檻是**最小值得做的效果**（Minimum Worthwhile Effect, MWE）：

$$\Delta_{\min}=\frac{C_{\text{固定}}+c\cdot N}{N\cdot m}$$

$N$ = 可觸及人數，$c$ = 每人變動成本，$C_{\text{固定}}$ = 活動固定成本，$m$ = 每單位指標改善的毛利。這與 M11 的損益兩平反應率是同一個式子的兩種寫法（見 `14_決策轉譯.md`）。【推導，待驗證】

**兩個方向相反的實例：**

| | 案例 A：小效果值得做 | 案例 B：大效果不值得做 |
|---|---|---|
| 情境 | 全站 EDM 改版，42 萬名收件人 | 群 3（47 人）專屬高端商品線 |
| 指標變化 | 轉換率 2.00% → 2.12%（lift +6%） | 客單價高出群 1 共 2,400 元 |
| 統計效果量 | Cohen's $h=0.0084$ ← **是「小」門檻的 1/24** | Cohen's $d=0.82$ ← **「大效果」** |
| $p$ 值 | $z=2.74$、$p=0.006$ | $t=5.06$、$p<0.001$ |
| 收益 | 504 筆增量訂單 × 380 元毛利 = **191,520 元** | $47\times2{,}400\times30\%=$ **33,840 元** |
| 成本 | 42 萬封 × 0.15 元 = 63,000 元 | 產品設計＋法遵＋通路訓練 ≈ 80,000 元 |
| 判定 | 淨 **+128,520 元**，做 | 淨 **−46,160 元**，不做（寫進「已考慮但排除」附錄） |

**這張表就是本節的結論**：Cohen 的門檻只用來回答「這個差異在統計上算不算大」，回答「該不該花錢」的是 $\Delta_{\min}$。兩者必須同時出現在建議欄，缺一個就會產生上表兩種反向錯誤之一。

```python
# 效果量與 MWE 一起算，缺一不可
from math import asin, sqrt
cohens_h = 2*asin(sqrt(0.0212)) - 2*asin(sqrt(0.0200))     # 0.00844
mwe      = (0 + 0.15*420_000) / (420_000 * 380)            # 0.000395 = 0.0395pp
# 實際提升 0.12pp > MWE 0.0395pp → 做（即使 h 只有 Cohen「小」門檻的 1/24）
```

## 三、多重比較校正

### 3.1 型一錯誤怎麼膨脹

教材給的族群錯誤率公式【教材：MBA5045 `01_eda_regression_anova.md` §10.8】：

$$\alpha_{ew}=1-(1-\alpha_{pc})^{k},\qquad k=\text{同族檢定數}$$

分群後的標準檢定套組：4 群 × 8 個人口變數的卡方 = 8 個檢定；5 個獲利指標的 ANOVA = 5 個；每個 ANOVA 接 $\binom42=6$ 個成對比較 = 30 個。合計 **43 個檢定**。若全部不校正：

$$\alpha_{ew}=1-0.95^{43}=0.889,\qquad \mathbb{E}[\text{假陽性}]=43\times0.05\approx 2.2$$

**89% 的機率至少有一個假顯著，期望值 2.2 個。** 這 2 個假顯著會被寫成兩條行銷建議，而它們看起來和真的一模一樣。

### 3.2 什麼算「一組」——這是唯一需要判斷的地方

**判準一句話：同一個決策所依賴的所有檢定 = 一族。** 族的邊界跟著**行動**走，不跟著章節走——因為型一錯誤的代價是「做了一個不該做的行動」。【推導，待驗證】

| 這批檢定 | 算不算一族 | 怎麼處理 |
|---|---|---|
| 分群 × 8 個人口變數的卡方 | **是**（8 個） | BH，$q=0.05$；原始 p 與 $p_{BH}$ 並報 |
| 5 個獲利指標各跑一次 ANOVA | **是**（5 個） | BH，$q=0.05$ |
| 同一個 ANOVA 內的 6 個成對比較 | **是，但已被 Tukey 控制** | **不可再套 BH**——Tukey 已控制 FWER，二次校正是重複校正【實測：`gap-statistical-inference.md` 更正建議 6】 |
| 探索性掃描 100 個品類的關聯 | **是**（100 個） | 必用 BH；且原始 p 全部列附錄 |
| 第 6 章的分群檢定 vs 第 10 章的促銷成效檢定 | **否** | 服務不同決策，各自成族 |
| 事前登錄的**唯一**主要假說 | **否**（$k=1$） | 不校正，但要在 M0 假說登錄表裡查得到「這是事前登錄的」 |
| 看到結果才想出來的假說 | **是，而且族很大** | 見 §七 P9（HARKing）；這種檢定不得單獨支撐建議 |

### 3.3 BH 還是 Bonferroni

**預設 BH（與 18-G8「統一 Benjamini-Hochberg FDR」一致）。** 只有在下表右欄的情境才切 Bonferroni。

**切換的判準是決策性質，不是 $m$ 的大小**——與 §3.2「族的邊界跟著行動走」同一個邏輯。下表任一列命中即適用；同時命中多列時，**只有「單一確認性結論」那一列可以覆蓋 BH**，其餘一律回到 BH。

Benjamini-Hochberg 程序：把 $m$ 個 p 值排序 $p_{(1)}\le\cdots\le p_{(m)}$，找**最大**的 $k$ 使

$$p_{(k)}\le\frac{k}{m}q$$

拒絕前 $k$ 個。Bonferroni 則是 $p_i\le\alpha/m$，或等價地把 p 值乘 $m$（教材的寫法是把臨界值改成 $t_{n-I,\frac{\alpha}{2k}}$，$k=\binom I2$）【教材：MBA5045 §11.6】。

| 情境 | 用哪個 | 理由 |
|---|---|---|
| 探索性掃描、輸出是一份名單、假陽性的代價 = 多發一批 DM | **BH（$q=0.05$）** | 控制的是「宣稱顯著者當中錯的比例」，這正好對應「名單裡有幾成是雜訊」 |
| 單一確認性結論、要押七位數預算 | **Bonferroni** | 控制的是「一個都不能錯」；此時保守是對的 |
| $m>20$ 且檢定彼此高度相關（同一批人的多個指標） | **BH** | Bonferroni 在此過度保守，檢定力崩掉，會把真效果全部殺光【教材：MBA5045 §11.6「當 $k$ 大或樣本小會偏保守、檢定力下降」】 |
| $m$ 很小（例如 $m\le5$）但仍是探索性的 | **BH** | ❌ 不要因為 $m$ 小就切 Bonferroni。$m=5$ 時 BH 最寬的臨界值是 $0.05$、Bonferroni 是 $0.01$，**差 5 倍**：$p=[0.011,0.012,0.013,0.014,0.015]$ 在 BH 下全拒絕、在 Bonferroni 下一個都不拒絕。「差異很小」在小 $m$ 時不成立 |
| 已用 Tukey / Games-Howell / Dunnett 的成對比較 | **都不用** | 已控制 FWER，見 3.2 |

## 四、樣本量 × 資料型態 → 該用什麼檢定

### 4.1 三個樣本量級距的定義

| 級距 | 定義 | 為什麼是這條線 |
|---|---|---|
| **大樣本** | 每組 $n\ge 30$ | CLT 對均值型統計量已足夠；卡方的大樣本近似另有 $E_{ij}\ge5$ 的獨立條件【教材：MBA5045 §5.6 F2】 |
| **小樣本** | $10\le n<30$ | 參數方法仍可用但要靠 Q-Q 圖判常態（Shapiro 在 $n<8$ 幾乎必過，檢定力趨近 0，見 `05 §六`）；**必須報 MDE** |
| **極小樣本** | $n<10$ | 任何漸近近似都不可信；只走精確法或重抽法；**必須報 MDE，且結論不得單獨支撐一條建議** |

**硬規則（本文最重要的一條）：任一組 $n<30$ 時，除了檢定結果還必須報檢定力或 MDE。** 這是 18-E16／E17 的升級版——「不顯著要列表」不夠，還要說明「這個樣本量本來能偵測多大的差異」【實測：`gap-statistical-inference.md` S12】。

### 4.2 完整決策表

「兩組」= 獨立兩樣本；「多組」= $k\ge3$ 獨立樣本。事後檢定的選擇見 §八。

| 資料型態 | 行銷例子 | 大樣本（每組 ≥30） | 小樣本（10–29） | 極小樣本（<10） |
|---|---|---|---|---|
| **連續近常態** | 標準化後的因素分數、log 客單價 | 兩組：**Welch's t**（預設，不必先檢變異數）<br>多組：one-way ANOVA + Tukey HSD | 同左，但常態改看 Q-Q 圖；**附 MDE** | Mann-Whitney U／Kruskal-Wallis；或 bootstrap BCa CI；**附 MDE** |

### 4.3 為什麼預設用 Welch 而不是 Student's t

Welch's t 在變異數相等時的效率損失可以忽略，在不相等時則明顯較準；而「先跑 Levene 再決定用哪個」本身是一次額外的資料窺探，會讓實際 $\alpha$ 偏離名目值。**兩組比較一律用 Welch，不做前置的變異數檢定。**【推導，待驗證】

注意這與 `05 §1.2` 的 ANOVA 規則不衝突：$k\ge3$ 時**先確認常態站不站得住，再照 Levene 的結果**決定走標準 ANOVA + Tukey 還是 Welch ANOVA + Games-Howell（兩層的完整決策樹見 §8.4），因為多組情境的事後檢定選擇確實同時依賴這兩個前提。

### 4.4 bootstrap 與排列檢定：什麼時候用哪個

| | bootstrap | 排列檢定（permutation） |
|---|---|---|
| 回答什麼 | **區間**：任意統計量的 CI（中位數、90 分位、CLV 加總、兩群比值） | **p 值**：在「組別標籤可交換」的虛無假設下 |
| 前提 | 觀測獨立同分布（交易列資料要用**顧客層重抽**，見 §七 P7） | 虛無假設下可交換 |
| 建議 B | $\ge2{,}000$（CI）；BCa 修正偏態 | $\ge10{,}000$ |
| B 的下限怎麼來 | — | p 值的 Monte-Carlo 標準誤 $\sqrt{p(1-p)/B}$；$p\approx0.05$、$B=10{,}000$ → SE = 0.0022，足以與 0.05 分辨【推導，待驗證】 |

## 五、穩健性檢定的四種形態

### 5.1 為什麼這一節比 p 值那一節更有說服力

$p<0.001$ 只說「在虛無假設下這麼極端的資料很罕見」。主管真正想知道的是**「換一批資料、換個做法，這個結論還在嗎」**——那是穩健性檢定回答的。一份寫得出「四項穩健性檢定，結論在三項下維持不變，在時間切點下方向不變但幅度從 +1,850 元降到 +1,100 元」的報告，說服力遠高於一份只有 $p$ 值的報告，**而且它讓自己可被反駁**，這正是 `00_通則 §2.2`「點名具體失效」的同一種紀律。

### 5.2 四種檢定的定義與判準

| # | 名稱 | 動什麼 | 具體做法 | 判定「不穩健」的門檻 |
|---:|---|---|---|---|
| **R1** | **離群敏感度** | 樣本中的少數個體 | 移除 Cook's D 最高的 1% 與 5% 各重估一次（Cook's D 門檻 $D\ge1$／$0.5$／$4/n$ 見 `05 §7.3`，不重寫） | 主係數**符號翻轉**，或顯著性在 $\alpha$ 兩側跨越，或 $|\hat\beta|$ 變動 >50% |
| **R2** | **子樣本穩定度** | 抽到的是誰 | ① 迴歸：cluster bootstrap（**以 `cust_id` 重抽**）$B=1{,}000$<br>② 分群：bootstrap ARI（**流程與 $B$ 見 `07 §7.2`，不重寫**——有放回抽樣 $n$ 位、$B=200$，不是隨機切半） | bootstrap 係數分布**跨 0 的比例 >5%**；分群 ARI 中位數 **<0.60**（門檻見 `07 §7.3`，不重寫；0.60–0.75 這一段 `verdict` 填 `stable_with_caveat`，不是 `unstable`） |
| **R3** | **模型設定敏感度** | 你做的建模選擇 | 至少四組對照：換連結函數（log vs identity）／加減共變量（tenure 進不進，18-G3）／換轉換（原始 vs $\ln$ vs $\sqrt{}$）／換標準誤（naive vs cluster-robust，見 §七 P7） | 係數方向在 **<80% 的設定**下一致；或顯著性只在單一設定下成立 |
| **R4** | **時間切點敏感度** | 你選的那個日期 | 換 `as_of`（±1、±3 個月）／換觀察窗長度（6／12／24 個月）／換標籤 horizon（3／6 個月） | 名單的 **Jaccard 重疊率 <0.6**，或效果方向翻轉 |

> ⚠ R2 的分群那一支 2026-07-27 修正過：原寫「隨機切半 50 次、ARI 中位數 <0.75 判不穩健【文獻：Hennig (2007)】」，三處都錯。(1) 門檻與流程是 `07 §7.3／§7.2` 的權責，本文重寫就會分岔——ARI 中位數 0.68 的專案會在 07 被判「可用但要標註」、在本文被判「不穩健」，同一份報告兩章互打。(2) 切半 50 次與 07 的「有放回抽樣 $n$ 位、$B=200$」不是同一個程序，切半只用一半資料重 fit，ARI 系統性偏低，配上更嚴的門檻是雙重加嚴。(3) Hennig (2007) 的 0.75／0.60 是**逐群 clusterwise Jaccard**，不是全域 ARI，兩者不是同一個統計量，掛【文獻】標記是誤用——07 §7.3 對同一組數字標的是【既有規格】／【推導，待驗證】。**照 R1 的寫法一律交叉引用，不重寫。**

**R2 的 cluster bootstrap 不是可選項。** 交易列資料直接對「列」重抽會低估變異——同一位顧客的 10 筆交易不是 10 個獨立觀測（ICC 判準見 `05 §1.3`）。重抽單位必須是分析想推論的單位，也就是顧客。

**時間不夠時的降級順序**：先跑 R1 與 R4。R1 最便宜（一次重估），R4 最常翻盤（行銷資料的季節結構強）。只跑兩項要在報告寫明「R2／R3 未執行」，不准默寫成「已做穩健性檢定」。【推導，待驗證】

### 5.3 報告寫法（包子指定的句型）

固定四段，**每一項都要給幅度，不只給「維持不變」**：

```

                （−3.2%），p 0.002 → 0.003。移除 5%（20 人，含 3 位年消費
                 前 1% 的大戶）後降至 1,240 元（−33%），p = 0.041。
```

| 增量（因果） | 「這檔活動帶來 X 筆增量訂單」 | **只有**隨機分派、地理實驗、或通過 `00 §1.5` 識別假設檢查的準實驗 |

### 6.4 抽樣設計決定你能算什麼（這條被漏掉的代價最大）

**回溯式（case-control）抽樣的樣本，比例與轉換率完全不可估，只有 OR 可估。** 教材原文：「你不能從這個樣本直接說『吸菸者罹癌率是幾 %』，因為 case／control 的人數是研究者自己設的」【教材：§5.3 C3】；「Retrospective product binomial sampling⋯只能用 odds ratio 檢驗，proportion 無法被估計」【教材：§5.3 C5】。

**行銷天天在做這件事而不自知**：「撈已購買 5,000 人 + 未購買隨機抽 5,000 人，回頭看誰曝光過廣告」就是回溯式抽樣。

| 抽樣設計 | 可估 | 不可估 | 行銷情境 |
|---|---|---|---|
| 隨機分派 | 比例、風險差、RR、OR、**因果效果** | — | A/B 測試、地理實驗 |
| 前瞻式（prospective） | 比例、RR、OR | 因果 | 先定曝光／未曝光名單，往後追蹤是否購買 |
| 橫斷面 / multinomial | 比例、OR | 因果、時序 | 某日全站快照 |
| **回溯式（case-control）** | **只有 OR** | **比例、轉換率、RR** | 先撈買／沒買名單，回頭比對觸點 |
| 未確認 | 只能當樣本描述 | 一切外推 | 行銷部給的「一份名單」——**必須回頭問清楚** |

**代價有多具體**【實測：`gap-statistical-inference.md` S3】：已購 5,000 人中 3,200 人曝光、未購 5,000 人中 1,800 人曝光。報告寫「曝光族群購買率 64%」並據此反推 CPA、編 800 萬預算。但真實母體購買率是 1.2%，那個 50% 的購買比例是研究者自己設的。**唯一可估的是 $\widehat{OR}=\frac{3200\times3200}{1800\times1800}=3.16$**，CPA 低估約 50 倍。

```
這批樣本是怎麼撈出來的？   ← M1 硬卡點必問，包子是唯一知道答案的人
   │
   ├─ 隨機分派 ─────────────────► 比例 / RR / OR 皆可；可談因果（仍附 CI 與事前 MDE）
   ├─ 前瞻式 ───────────────────► 比例 / RR / OR 皆可；不可談因果
   ├─ 回溯式（先定結果再看曝光）─► **只准報 OR**；任何 `率` / `CVR` / `轉換` 欄位一律 fail
   └─ 不知道 ───────────────────► 報告插入固定警語：
                                   「抽樣設計未確認，本節比例僅為樣本描述，不可外推至母體」
```

## 八、ANOVA 與事後檢定的綁定

### 8.1 為什麼這條被單獨拉出來

18-E1 是全班最大扣分群：**27 人核心分析全部完整，只因為 ANOVA 做完就停，A+ 掉到 A**。綁定規則是硬的——`ANOVA → 事後檢定` 不可分離，跑不出來要降級並說明，不准留空。教材的說法更直白：「ANOVA 只告訴你『至少有一組不一樣』，**主管真正要問的是『哪一個最好』**」【教材：MBA5045 §10.10 評註】。

### 8.2 一個必須先講的例外：分群輸入變數不可跑 ANOVA

**E1 的綁定只適用於「非分群輸入變數」的 ANOVA。** 對 R／F／M／CAI／CRI／因素分數（也就是 18-E2 的分群白名單）跑 ANOVA 是**循環推論**：Ward 與 k-means 的目標函數就是最小化 WGSS，而 $F=\frac{BGSS/(k-1)}{WGSS/(n-k)}$ 正是被最佳化的那個量。把 100 位客戶換成純隨機常態噪音跑同一條 pipeline，一樣會得到 $p<0.001$【實測：`gap-statistical-inference.md` S1】。

| 變數類型 | 可以做什麼 | 不可以做什麼 |
|---|---|---|
| **分群輸入變數**（R/F/M/RFM Score/CAI/CRI/因素分數/LN_F/LN_M） | 群均值、95% CI、$\eta^2$；表標題強制加註「（分群輸入變數，此處數字為描述性，不作顯著性檢定）」 | **輸出物件不得有 p 值欄位** |
| **非輸入變數**（人口統計、分群後期間的行為、未進分群的獲利指標） | 完整 ANOVA → 事後檢定 → 卡方，E1 綁定全額適用 | — |
| 「分群是否真實」的證據 | permutation / gap 參考分布的 `structure_pvalue`（$B=200$） | 用組間 ANOVA 的 p 值當「分群有效性」的依據 |

### 8.3 事後檢定選擇表

共同 t 統計量【教材：MBA5045 §11.6】：$t_{ij}=\dfrac{\hat\alpha_i-\hat\alpha_j}{\hat\sigma\sqrt{1/J_i+1/J_j}}$，$\hat\sigma=\sqrt{MSE}$，$\mathrm{df}=n-I$。

| 方法 | 拒絕域 | 教材評價（原文） | 什麼時候用 |
|---|---|---|---|
| **Fisher LSD** | $\lvert t_{ij}\rvert>t_{n-I,\alpha/2}$ | 「本質上等於兩獨立樣本 t 檢定，只適合單一（或極少數）**事先規劃**的比較。是三者之中**最寬鬆**的方法。」 | 只有 1–2 個事前登錄的比較時 |
| **Bonferroni** | $\lvert t_{ij}\rvert>t_{n-I,\frac{\alpha}{2k}}$，$k=\binom I2$ | 「是三者之中**最嚴謹**的方法。」缺點：「$k$ 大或樣本小會偏保守、檢定力下降。」 | 要押大預算、一個都不能錯時 |
| **Tukey HSD** | $\lvert t_{ij}\rvert>\dfrac{q_{I,\mathrm{df},\alpha}}{\sqrt2}$ | 「針對**所有成對比較**且等變異及常態假設合理時**最推薦**。樣本數不相等時，**自動選擇 Tukey–Kramer procedure**。是三者中**較適中**的做法。」 | **預設** |
| **Games-Howell** | Welch 型 SE + studentized range | 教材未涵蓋 | Levene 不過時（`05 §1.2` 的通行證） |
| **Dunn（BH）** | 秩和的成對比較 | 教材未涵蓋 | Kruskal-Wallis 之後（`scikit_posthocs.posthoc_dunn`） |
| **Dunnett** | 各組 vs 單一對照組 | 教材未涵蓋 | 「現行方案 vs 3 個新方案」——行銷最常見的設計，比較數從 $\binom42=6$ 降到 3，檢定力更高 |

**同一組資料、三種方法的實際落差**【實測：MBA5045 `01_eda_regression_anova.md` §11.6，第 3 組 vs 第 5 組】：

| 方法 | 檢定統計量 | 臨界值 | p 值 | 結論 |
|---|---:|---:|---:|---|
| Fisher LSD | $t=3.052$ | 1.966 | 0.00243 | 顯著 |
| Bonferroni | $t=3.052$ | 2.8239 | 0.02437 | 顯著（強度明顯下降） |
| **Tukey HSD** | $t=3.052$ | 2.7412 | 0.0205 | 顯著 |

三個 p 值差了一個數量級，而資料一模一樣。**這就是為什麼「用哪個事後檢定」必須事前決定並寫進 `params.yml`（`00 §1.4`），不能看到 p 值再挑。**

### 8.4 選擇與降級的決策樹

```
拒絕 ANOVA 的 H0（至少一組不同）
   │
   ├─ 這個變數是分群輸入變數嗎？
   │     └─ 是 ──► 停。只出描述統計 + CI + η²，不做顯著性檢定（見 8.2）
   │
   ├─ 比較結構是什麼？
   │     ├─ 各組 vs 單一對照組 ──────────────► Dunnett
   │     └─ 所有成對比較
   │           │   ⚠ 常態與變異數同質是「兩個獨立維度」，必須分兩層問。
   │           │     排成同一層的三個平行分支會讓最後一支永遠走不到
   │           │     （偏態 + 等變異的資料會先被「等變異」那支攔走）
   │           │
   │           └─ 第 1 層：常態站得住嗎？（偏度 < 1，或轉換後 < 1）
   │                 │
   │                 ├─ 是 ──► 第 2 層：Levene p > 0.05 且 變異數比 < 4？
   │                 │           │        （門檻不重寫，見 05 §1.2 通行證表）
   │                 │           ├─ 是 ──► **Tukey HSD**（預設，n 不等自動走 Tukey–Kramer）
   │                 │           └─ 否 ──► Welch ANOVA + **Games-Howell**（見 05 §1.2）
   │                 │
   │                 └─ 否（偏度 ≥ 1 且轉換無效）
   │                             │
   │                             ├─ 變異數比 < 4 ──► Kruskal-Wallis + **Dunn（BH）**
   │                             └─ 變異數比 ≥ 4 ──► **Games-Howell**，或 bootstrap BCa
   │                                                  的成對均值差 CI
   │                                                  （KW 在異方差下型一錯誤失控，
   │                                                    不可當萬用退路）
   │
   └─ 以上都跑不出來（套件失敗、某群 n < 5、變異數為 0）
         ▼ 降級階梯（與 00 §1.6 一致，只准往「前提更少」的方向退一格）
         手動獨立樣本 t（對 C(I,2) 個 p 值套 BH）
              │ 仍不行
              ▼
         敘述統計 + 95% CI 對照表，並明寫「本節無法主張群間差異」
         （章節保留，不准刪，見 18-E11；降級寫進 執行紀錄/degradation_log.md）
```

**兩條不可違反的附加規則**：

1. **Tukey／Games-Howell／Dunnett 之後不得再套 BH。** 它們已控制 FWER，二次校正是重複校正（見 §3.2）。只有**手動 t 檢定**的降級路徑才需要 BH。
2. **α 放寬必須聲明。** 分群後某群 $n=47$ 時放寬到 $\alpha=0.20$ 是合法的，但要在表標題或內文明寫「顯著水準放寬至 $\alpha=0.20$」並說明理由（18-E18），且 `params.yml` 的 `alpha` 條目要填 `sensitivity`（$\alpha=0.05$ 時哪幾條會被降下來）。
