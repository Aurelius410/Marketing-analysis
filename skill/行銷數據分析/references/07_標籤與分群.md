# 標籤與分群（M5／M6）

這份文件管兩件事：**M5 把已知的業務規則寫成標籤（選做）**，**M6 從行為指標裡把未知的結構找出來（必做）**。兩者的差別不是難度，是**知識來源**——M5 的分界線是人訂的、寫在公司文件裡；M6 的分界線是資料自己長出來的，沒有人可以事先背書。把兩者混在一起做，就會出現最常見也最貴的那種分群：用會員等級去「驗證」分群結果，然後宣稱分群有效。

M6 的失敗有一個特徵：**它不會報錯，也不會看起來可疑**。K-Means 對任何一批數字都會吐出 k 群，ANOVA 對這 k 群一定會顯著（見 §八 的 S1），每群都可以編一個名字，圖畫出來也有四團顏色。整份章節從頭到尾沒有一個地方會亮紅燈。真正的代價發生在半年後：行銷團隊照著「群 2 是中頻中額的穩定客」發了會員日回饋，回應率只有預期的四分之一——因為那個群裡同時有「一年買一次筆電」和「每週買一次配件」的人，他們的維繫策略完全相反（實測情境見 `05_資料特徵檢驗.md` §1.5，3C 資料尺度比 6,112）。

本文與其他 reference 的分工：**橫切紀律**（參數必附理由、降級不留空、空值符號）在 `00_通則與紀律.md`；**具體陷阱**（E/G/T 條目）在 `18_分析陷阱清單.md`，本文一律用「見 18-Exx」引用不重抄；**公式**在 `17_指標公式庫.md`，本文不重寫 R/F/M/CAI/CRI 的定義；**圖表規格**在 `19_圖表與統計表規格.md` §1.4。進來之前，M4 的三個門檻（偏度 <1、變異數同質、排序相關 >0.95）必須已經有結論。

> **標註體例**：本文所有數字都標出處。【實測】= 素材中有實際量測值；【教材】= 課程講義原文；【素材建議】= 缺口審查文件開出的處方；【推導，待驗證】= 本 skill 自訂、尚未在包子的資料上驗證過。**沒有標籤的數字視同錯誤。**

## 一、M5 業務規則標籤（選做）

### 1.1 什麼算業務規則標籤、什麼不算

M5 只做一件事：**把公司已經寫在文件裡的分界線，忠實地翻譯成資料欄位**。它的知識來源是外部的、可被引用的，不是從這批資料學來的。

| 是 M5 標籤 | 不是 M5 標籤（該去哪） |
|---|---|
| 會員等級規則（年消費滿 5 萬升金卡） | 分群結果的群別 → M6 |
| 品類的商業角色（引流品／利潤品／長尾） | 因素分析的因素分數 → M8-2（`10_行銷_購物籃與品類.md`） |
| 通路與活動的既有分類（自然流量／付費／EDM） | 「高價值客」這種沒有成文定義的形容詞 → 先回 M0 定義 |
| 流失定義（若公司已有成文口徑） | 監督學習的目標變數 → **不在這裡**，見 §1.4 |
| 商品生命週期階段（新品／主力／清倉） | 顧客人格命名 → **不在這裡**，見 §九 |

**沒有成文規則就跳過整個 M5，不要自創規則**（`00_通則與紀律.md` §五已經寫死）。自創的業務規則有一個致命性質：它看起來像外部知識（因為它是人訂的），但實際上是從這批資料看出來的（因為你是看完分布才訂的門檻）。下游拿它去驗證分群，就變成用資料驗證資料。

### 1.2 門檻要有理由——四欄制

每一個標籤的每一個門檻，都要在 `params.yml` 佔一段，四欄缺一不可（格式沿用 `00_通則與紀律.md` §1.4）。**「無明文」是包子既有檔案最大的系統性缺口**：HW2 盤點的 7 個參數、HW5 盤點的 8 個參數，「有無理由」欄**全部 15 格都是「無明文」**【實測，出處：`gdrive/own/02_包子自己的計算檔逐步拆解.md` §2.4、§4.5】。這一節就是為了把那 15 格填起來。

```yaml
# projects/<代號>/params.yml —— M5 標籤段
label_high_value_member:
  value: "年消費 >= 50000 AND 交易次數 >= 6"
  reason: "沿用 2025 版《會員權益辦法》第 3 條的金卡門檻，非本次分析自訂"
  source: "公司文件《會員權益辦法 v2025.03》第 3 條；已與行銷部王經理口頭確認仍生效"
  sensitivity: "門檻改 40000 → 標記人數 1,240 → 1,690 人（+36%）；營收覆蓋率 62% → 71%。
                結論方向不變，但 §11 的 sizing 要重算"
```

第四欄「敏感度」不是形式：**必須真的跑一次**。門檻換一個值就翻盤的標籤，不能拿去做預算決策，這件事只有跑過才知道。

### 1.3 與既有業務分類的對應

兩者的關係要在 M5 就講清楚，不能等 M6 才發現衝突。做法是一張**對應矩陣**：列＝你造的標籤，欄＝公司既有分類，格內填人數，最後一欄填「這個標籤在既有分類之外多說了什麼」（下表為格式示範，數字虛構）。

| M5 標籤 | 金卡 | 銀卡 | 一般 | 這個標籤多說了什麼 |
|---|---:|---:|---:|---|
| 高頻低額 | 41 | 388 | 1,205 | 銀卡裡有 388 人的行為與金卡同型，等級制度沒抓到 |
| 低頻高額 | 173 | 96 | 44 | 與金卡高度重疊（覆蓋率 63%），**資訊量低，考慮不做** |
| 沉睡 | 22 | 210 | 2,890 | 等級不隨時間衰減，所以完全抓不到沉睡 |

最後一欄填不出東西的標籤直接刪掉——它只是既有分類的別名。這與 `00_通則與紀律.md` §2.4「升級後不改變任何決策就不要升級」同源：**重疊率 > 90% 的標籤沒有存在價值**【推導，待驗證；門檻沿用 §2.4 的既有 90%】。

### 1.4 M5 明確不做的三件事

| 不做的事 | 為什麼 | 該在哪做 |
|---|---|---|
| **監督學習的目標變數** | 目標變數必須綁 `as_of_date` 與標籤窗，兩者要分離。在 M5 造一個「會不會流失」欄，等於用全期資料造標籤，下游 AUC 0.95 上線崩盤（18-G4） | M9，見 `12_預測建模.md` |
| **分群的人格命名** | 命名需要群的相對輪廓（index/lift），M5 時還沒有群 | M6 之後，見 §九 |
| **把人口統計欄變成分群輸入** | 18-E2 的白名單不含人口變數，理論依據見 §三 | 人口變數只准出現在 §八 的卡方那一章 |

## 二、分群階梯 ★

這是 `00_通則與紀律.md` §二在分群領域的實作。**前提最少的先做，升級的理由必須是「前一層在這批資料上的具體失效」，而且要點名 ID 或數字**——抽象說詞（「k-means 不夠穩健」「球形假設太強」）在任何資料上都成立，因此在這一批資料上什麼都沒證明。

```
L0 既有業務分類 ──────► L1 K-Means ──────► L2 Ward + K-Means ──────► L3 GMM ──────► L4 HDBSCAN
   前提：1 個既有欄位      前提：5 道關      前提：n ≤ 數千          前提：n ≥ 10p·k  前提：有密度落差
   （§四）                （§四全過）       （HAC 是 O(n²)）        （每成分 ≥ 10p）  （不保證有結構）
        │                     │                    │                     │                │
        └─ 組內變異吃掉組間   └─ seed 不穩          └─ 邊界重疊          └─ 成分退化       └─ 終點：不再升級，
           （η² < 0.10）        （ARI < 0.75）        （s(i)<0 超過 20%）    或 BIC 不收斂      改跨方法比對（§六）
```

### 2.1 五層各自的三件事

| 層 | 先做它的理由 | 需要什麼前提 | 什麼具體現象代表要升級（**必須點名**） |
|---|---|---|---|
| **L0 既有業務分類** | 前提最少：只要 1 個既有欄位（會員等級／卡別／通路），零建模、零參數、行銷團隊已經看得懂 | 該欄位有成文定義且仍生效（§1.2） | 組內變異吃掉組間差異。判準：對主要獲利指標算 $\eta^2 < 0.10$【推導，待驗證】。**點名寫法**：「金卡與銀卡的月均消費差 1,100 元，但金卡組內 sd = 3,480 元，是該差距的 3.2 倍——等級解釋不了行為差異」 |
| **L1 K-Means** | 教材定位為 **default / baseline**：「不知道用什麼算法時先試 K-means」【教材】。快、可擴展、群心可解釋、行銷團隊能理解 | §四 五道關全過 | ① seed 不穩：k-means++ 換 10 個 `random_state`，兩兩群成員 ARI 中位數 < 0.75【推導，待驗證】；② elbow 無肘部或有多個肘部；③ 三指標互相矛盾（§五）。**點名寫法**：「seed=0 與 seed=7 的成員 ARI = 0.41，群 2 有 63 人換了群」 |
| **L2 Ward + K-Means 兩階段** | Ward 先定 k 與初始群心，K-Means 再精修。兩者**目標函數同源**（都最小化 WGSS），不是互相矛盾的準則【教材推論；`03_clustering_sequence.md` §9.5 明示教材只在延伸閱讀列了 Ward 1963 的論文標題，此論證由教材原理推出】。附帶好處：dendrogram 給了 k 的第四種證據 | HAC 是 $O(n^2\log n)$ 時間、$O(n^2)$ 空間。教材原話：「HAC 最適合處理幾百到幾千規模的資料」【教材】。n > 3 萬要先抽樣或改走 L1 | 群邊界重疊：任一群有 > 20% 樣本 $s(i)<0$，或「離最近兩群心距離差 < 10%」者佔比 > 15%【均為推導，待驗證】。**點名寫法**：「群 3 的 47 人中 14 人 $s(i)<0$；客戶 #1729 到群 3 群心 2.14、到群 1 群心 2.19，差 2.3%——硬分配沒有意義」 |
| **L3 GMM** | 軟分群，給每位顧客 $P(c_j\mid x_i)$ 而不是硬標籤。教材原話：硬分群的缺點是「邊界點被迫分配到一個簇」【教材】。行銷用途具體：推薦模型的特徵、「這位有多像 VIP」的傾向分數 | 參數量大：full covariance 下每個成分要估 $p(p+3)/2$ 個參數，**每成分至少 10p 筆樣本**才穩定【推導，待驗證；沿用迴歸的 $n\ge10p$ 慣例，見 `00_通則與紀律.md` §五 M7 列】。$p=5$ 時**每成分最低 50 筆**，$k=4$ 時全樣本最低 $10p\cdot k\approx200$ 筆 | ① 成分退化：某成分共變異矩陣接近奇異（條件數 > 1e6）；② BIC 對 k 單調下降不收斂；③ 有 5–10% 的樣本在**所有**成分下 $\max_j P(c_j\mid x_i) < 0.5$【推導，待驗證】——這批人不屬於任何高斯，是密度訊號 |
| **L4 HDBSCAN** | 不預設群數、不預設球形、**會誠實回答「這批資料沒有密度結構」**。這是前四層都做不到的一件事：L0–L3 一定會給你 k 群，不管群存不存在 | 需要有密度落差可言。維度愈高愈失效——教材對 DBSCAN 的評價是高維「差（距離度量失效，維度詛咒）」，K-Means 是「尚可」【教材】。輸入維度 > 8 先降維或減變數 | **HDBSCAN 是終點，不再往上升級。** 它的輸出不是取代 L1–L3，而是與它們**交叉比對**（§六）。比對結果決定要相信誰 |

### 2.2 什麼時候停在原地

階梯不是愈高愈好。以下三種情況停下並把理由寫進報告（規則沿用 `00_通則與紀律.md` §2.4）：

| 情況 | 判定 | 處理 |
|---|---|---|
| 前一層沒有失效 | 找不到可點名的失效證據 | 停。寫「K-Means 在本批資料上未觀察到失效（10 seed ARI 中位數 0.88），因此不升級到兩階段」 |
| 升級後不改變任何決策 | 兩層的群成員 ARI > 0.90，或名單重疊 > 90% | 停。用低的那層，附錄放 ARI 與重疊率 |
| 升級要的前提沒有 | GMM 需要每成分 ≥ 10p，但這批只有 150 人 | 停，並在報告寫「n=150、p=5、k=4 → 每群約 37 筆 < 50，GMM 的共變異矩陣估不穩，不做」 |

### 2.3 M6 不可用時的降級

`00_通則與紀律.md` §五已經規定 M6 的最低條件：**≥2 個行為指標欄、顧客數 ≥ 50**。不滿足時的降級路徑是既有階梯的反向：

```
分群不可用
   │
   ├─ 可用行為指標只有 1 欄 ──► 分位切割（NTILE(5) 或 20/60/20），明寫「這是單變數切割，不是分群」
   │
   ├─ 顧客 < 50 ──────────────► 分位切割 + 業務規則標籤（§一）
   │      理由：k=4 時每群約 12 人，依 00_通則 §四 的 MDE 算式已無檢定力
   │
   └─ 兩者皆缺 ──────────────► 敘述統計對照表 + 明說「本節無法主張存在顧客區隔」
                                 章節保留，不准整章刪（18-E11）
```

## 三、分群輸入變數白名單

### 3.1 白名單本身

**分群輸入只能是行為指標**（18-E2）。白名單如下，多一個都不行：

| 允許的輸入 | 用哪個版本進矩陣 | 為什麼 |
|---|---|---|
| `R`（最近購買間隔天數） | **先過 §3.3 Step 1 的偏度檢查**：$\lvert\text{skew}\rvert\le1$ 才用原值 z-score，否則依 06 §六 改 `NTILE(5)` 分位分箱後 z-score | 不要預設 R 不偏。課程資料集 R ∈ [1, 516]、p50 = 12、mean 73.8、sd 129.5、**skew = 2.09**【實測，出處 `local/資料集剖析/marketing_datasets_profile.md` RFM 分位表；本次已由 `ntu_creditcard__transactions.parquet` 以 `as_of=2012-12-01` 複算】——右偏，過不了 §四 關卡 2。**時間型欄位不宜 log**（30↔60 與 300↔600 會被壓成同樣差距，見 06 §4.5），故 `06_前處理與轉換.md` §六 對 `r_days_since_last_sale` 的裁定是分位分箱（切點 3.0 / 5.0 / 22.4 / 113.8） |
| `F`（交易筆數） | **`LN_F`** 後 z-score | 右偏。欄名須帶口徑（`f_txn_cnt` vs `f_active_days`，客單價因此差 23%，見 17 §二） |
| `M`（消費金額，淨額） | **`LN_M`** 後 z-score | 極度右偏。課程資料集 M ∈ [583, 1,153,973]、p50 = 76,432、sd 218,943【實測，出處同 R 列；150,681 是 17 §八 三位驗證基準客戶之一（客戶 89）的個人值，**不是母體上界**，不要拿它當值域】 |
| `RFM Score` | 原值 z-score | 已是 1–5 的分數，不需轉換 |
| `CAI` | 原值 z-score | 可正可負（`CAI>0` = 節奏加快），**不可 log**。且必須帶 `n_intervals`，< 5 者的 CAI 一律 `N/A`【素材建議，出處：`gap-statistical-inference.md` S6】 |
| `CRI` | 原值 z-score，**且受右欄血緣限制** | 同上，收縮量指標。**但 CRI 不是純行為量**：$\mathrm{CRI}_i\equiv W_2\times100$，而 $W_2=\dfrac{s_i^2/n_i}{\tau_g^2+s_i^2/n_i}$ 的分母含**該顧客所屬先驗群的群內變異數** $\tau_g^2$（見 `09_行銷_顧客價值.md` §2.1）。先驗群若照包子 HW4 用「性別 × 地區」分，交易紀錄完全相同的兩人也會因人口欄不同而拿到不同 CRI（以 09 §2.1 兩個實測 $\tau_g^2$ 代入，同一個 $s_i^2/n_i=10^7$ 時 CRI 差到 21.4 vs 79.1），等於把本表下方「明確禁止」那一行的人口變數以非線性編碼送進矩陣。**規則**：僅當 `cluster_spec.json` 的 `cri_prior_type == "behavioral"`（先驗群以行為分層，如 F 三分位、品類廣度）時 CRI 才可進分群輸入；先驗群用人口變數時，CRI 不進矩陣，或依 §8.4 的排除條款處理 |
| 因素分數（購物籃／品類） | 已標準化，不再 z-score | 因素分析輸出本身即為標準分數 |

**明確禁止**：性別、年齡、婚姻、地區、郵遞區號、教育程度、職業、收入、家庭組成、族群國籍、卡別、會員等級、任何 M5 標籤。判定清單是 `scripts/demographic_vars.py`（中文欄名子字串比對、英文欄名詞界比對），18-E2 的白名單檢查與下面的 CRI 血緣判定共用同一份 —— 各寫一份就會出現只有攻擊者知道的破洞。要新增類別改那一支，不要改呼叫端。

**CRI 血緣怎麼驗（實作）**：上面那條「僅當 `cri_prior_type == "behavioral"`」如果只讀 `cluster_spec.json`，就是**自我宣告** —— 先驗群明明用性別分，spec 填 `"behavioral"` 一樣放行（實測：`--prior-group-cols 性別` 算出的特徵表，`prior_group` 欄值直接寫著 `1:男`／`2:女`，舊版仍印「✅ CRI 血緣通過」）。所以血緣要**跟著資料走**：

- `build_features.py` 把先驗群的機器可讀血緣寫進顧客特徵表（parquet 與 DuckDB 皆有）三欄 —— `prior_group_type`（`none`／`behavioral`／`demographic`／`mixed`）、`prior_group_cols`（實際用哪些欄算的）、`prior_group_demographic_cols`（其中哪些命中人口變數清單），另寫一張 `meta_cri_lineage` 表記 `as_of` 與維度來源。
- `prep_cluster_matrix.py` 讀特徵表的 `prior_group_cols` **重新判定**一次，以資料為準；`cluster_spec.json` 的 `cri_prior_type` 降級為交叉檢查。放行條件是**資料判定與 spec 宣告都是 `behavioral`**；兩者不一致 → error 並印出「資料說什麼、spec 說什麼」；spec 沒填 → error（這一條不因為資料可驗就免除）。
- 特徵表若沒有這三欄（舊版產的），退回只看 spec 的自我宣告，並發 warning 明講「這一關現在沒有牙齒」，要求重跑 `build_features.py`。
- `behavioral` 的語意是「先驗欄位沒有命中人口變數清單」，不等於已證明是行為量 —— 清單不可能窮盡所有人口欄名，所以欄位名一起寫進資料，供人覆核。

### 3.2 理論依據（要能背出來）

> 「消費者行為隨時會變；但是行為本質的分類是不變的。行銷要從**行為本質**的基礎做策略發展，**不是**以**成員結構**的描述去發展。」
> ——IB5082 第一講 P26 原文【教材，經 18-E2 引用】

一句話的操作意涵：**人口統計分群的定義會腐爛，行為分群的定義才穩定。** 25 歲的人三年後 28 歲，「25–29 歲群」的成員全換了但名字沒變；「每 10 天買一次、客單 800 元」這個群的定義三年後還是同一件事。

人口變數不是沒有用，是**位置不同**：它們在 §八 的卡方獨立性檢定裡當「輪廓描述」，回答「這四群人的組成長得一樣嗎」。**先分群、再看人口組成**是對的；**先用人口分群、再看行為**是錯的。

| # | 關卡 | 怎麼檢查 | 門檻 | 沒過怎麼辦 |
|---|---|---|---|---|
| **1** | **尺度已標準化** | 尺度比 $\max_j \mathrm{sd}(x_j)/\min_j \mathrm{sd}(x_j)$ | > 10 必須標準化 | 標準化。z-score fit 在**整個分析集**（非監督沒有 train/test，見 `06_前處理與轉換.md` §5.2）。有離群且已走完 §三 → RobustScaler。**沒做就是禁行，不是警告**【出處：`05_資料特徵檢驗.md` §1.5】 |
| **2** | **右偏欄已轉換** | 各輸入欄的 skew | $\lvert\text{skew}\rvert \le 1$（M4 三門檻之一） | 依 `06_前處理與轉換.md` §1.2 順位表：右偏全正 → `log(x)`（分群輸入屬「只做描述」，用第二順位即可）；右偏含 0 → Yeo-Johnson。轉換後要複檢排序相關 > 0.95 |
| **3** | **無極端值主導** | 單一變數對 WGSS 下降的貢獻百分比；離群結構（`05_資料特徵檢驗.md` §1.6） | 任一變數 > 70% → warning【素材建議】 | 先分辨「單點」還是「次族群」：< 1% 且無結構 = 單點，查輸入錯誤；≥ 5% 或密度圖雙峰 = **次族群，不准刪，分開建模**。先轉換再看還有沒有離群，**絕不先 winsorize**（SKILL.md 負面清單） |
| **4** | **球形簇假設** | 跑完後對每群算共變異矩陣的條件數 $\kappa=\sqrt{\lambda_{\max}/\lambda_{\min}}$；並與 HDBSCAN 交叉比對（§六） | $\kappa > 10$ 代表該群明顯拉長【推導，待驗證；沿用 `05` §1.4 條件數 30 的一半，因為這裡是群內不是設計矩陣】 | 升級到 L4 HDBSCAN，或改用 GMM 的 full covariance。**教材原話**：K-Means「假設簇呈球形，對非凸形狀效果差」【教材】 |

```python
# scripts/kmeans_preflight.py —— 五道關，回傳 exit code 0/1/2（沿用 setup_check 的語意）
import numpy as np, pandas as pd
from scipy import stats

def preflight(X_raw: pd.DataFrame) -> dict:
    sd = X_raw.std(ddof=1)
    out = {
        "gate1_scale_ratio": float(sd.max() / sd.min()),          # 門檻 <=10 或已標準化
        "gate2_skew":  {c: float(stats.skew(X_raw[c].dropna())) for c in X_raw},  # 門檻 |skew|<=1
    }
    out["gate1_pass"] = out["gate1_scale_ratio"] <= 10
    out["gate2_pass"] = all(abs(v) <= 1 for v in out["gate2_skew"].values())
    return out            # gate3 由 prep_cluster_matrix 的 WGSS 貢獻表提供
                          # gate4/gate5 需要 labels_，在 fit 之後呼叫 postflight()
```

## 五、k 怎麼決定

### 5.1 三個指標各自在測什麼

**教材立場先講清楚**：教材唯一給公式且「可自動最大化」的 k 選擇指標是 **CH Index**；Elbow 教材明說「客觀性低（靠人眼）、主觀性強」；**Silhouette 只被列名沒有公式、Gap Statistic 完全沒有、分群穩定性／bootstrap 驗證完全沒有**【教材，出處：`03_clustering_sequence.md` §4.4、§15 自列缺口】。所以下面的 silhouette 與 gap 是本 skill 補的，不是教材規則。

$$\text{Elbow:}\quad \mathrm{WGSS}(k)=\sum_{j=1}^{k}\sum_{x_i\in c_j}\lVert x_i-\mu_j\rVert^2,\qquad
\text{改善率}(k)=\frac{\mathrm{WGSS}(k-1)-\mathrm{WGSS}(k)}{\mathrm{WGSS}(k-1)}\times100\%$$

$$\text{CH:}\quad \mathrm{CH}(k)=\frac{\mathrm{BGSS}/(k-1)}{\mathrm{WGSS}/(n-k)}\qquad(\text{愈大愈好})$$

$$\text{Silhouette:}\quad s(i)=\frac{b(i)-a(i)}{\max\{a(i),\,b(i)\}}\in[-1,1],\qquad \bar s(k)=\frac1n\sum_i s(i)$$

$$\text{Gap:}\quad \mathrm{Gap}(k)=\mathbb{E}^*_B[\log W_k]-\log W_k,\qquad
s_k=\mathrm{sd}_B(\log W_k)\sqrt{1+\tfrac1B}$$

| 指標 | 它在測什麼 | 判準 | 它抓不到什麼 |
|---|---|---|---|
| **Elbow / WGSS** | 增加一群還能不能顯著壓低群內離散 | 改善率首次跌破 **5%** 的前一點【教材，投影片示例即以「改善率 <5%」判肘部】 | WGSS 對 k 單調遞減（$k=n$ 時 $=0$），**不能拿 WGSS 本身當「愈低愈好」的準則**【教材明示】 |
| **CH Index** | 群間離散 ÷ 群內離散，含自由度校正 | $k^*=\arg\max_k \mathrm{CH}(k)$【教材】 | 對球形簇有偏好；與 K-Means 目標函數同源，所以它不能證明「群是真的」（見 §八 S1） |
| **Silhouette** | 每個點「離自己群近多少、離最近他群遠多少」 | $\bar s \ge 0.50$ 結構明確；$0.25\le\bar s<0.50$ 結構弱但可用；$\bar s<0.25$ 無實質結構【推導，待驗證】。**同時看剖面圖**：任一群 > 20% 樣本 $s(i)<0$ 即為該群邊界失效 | 平均值會被大群蓋過，**只看 $\bar s$ 不看剖面圖等於沒看** |
| **Gap Statistic** | 實際的 $\log W_k$ 比「同尺度隨機參考資料」低多少 | 取**最小的 k** 使 $\mathrm{Gap}(k)\ge \mathrm{Gap}(k+1)-s_{k+1}$（Tibshirani 準則）【推導，待驗證；教材完全沒有 gap】 | 參考分布的產生方式（uniform hypercube vs PCA-aligned box）會改結果，必須記進 `cluster_spec.json` |

`B` 取 **200**【素材建議，出處：`gap-statistical-inference.md` S1 修補動作 2 的 `B=200`】。

### 5.2 三者不一致時怎麼辦

**不一致是常態，不是異常。** 規則是硬的，不准挑一個看起來合理的用：

| 情況 | 判定 | 動作 |
|---|---|---|
| 三者指向同一個 k | 罕見，直接採用 | 仍要走 §5.3 的後三步 |
| **Elbow 無肘部或有多個肘部** | Elbow 棄權，不算一票 | 用 silhouette + gap 兩票。教材對此有先例：DBSCAN 的 k-distance 圖「曲線可能有多個較明顯的肘部，需要領域知識判斷」，同一個病理【教材】 |
| **silhouette 與 gap 相差 1** | 取小的那個 | 群少比群多安全：群多的代價是行銷團隊做不出這麼多套素材（§5.3 第 2 步會擋掉） |
| **silhouette 與 gap 相差 ≥ 2** | **停。這是尺度或轉換沒做好的訊號** | 回 §3.3 檢查 WGSS 貢獻表。單一變數 > 70% 時三指標必然打架 |
| **gap 的最佳 k = 1** | **這批資料可能沒有群結構** | 不要硬分。走 §六 的 HDBSCAN 交叉比對，並準備誠實說明（見 §6.2 情況 B） |
| **CH 單調上升到 $k_{\max}$** | CH 失效 | 忽略 CH，用 silhouette + gap。同時檢查是否有極端值把 BGSS 撐大 |

### 5.4 k 的理由要寫成什麼樣

`params.yml` 的 `k` 那一段，四欄的填法（沿用 `00_通則與紀律.md` §1.4 對 k 的規定：elbow／silhouette／gap 的**實際數值** + bootstrap ARI + **行銷團隊同時經營得了幾群**）：

```yaml

  value: 4
  reason: "elbow 改善率 k=4 時 6.1%、k=5 時 3.2%（首次 <5%）；silhouette k=4 為 0.41、
           k=5 降到 0.33；gap 準則取 k=4（Gap(4)=0.318 >= Gap(5)-s5 = 0.341-0.029）。
```

## 六、K-Means × HDBSCAN 交叉比對 ★

### 6.1 為什麼要做這件事

L1–L3 有一個共同性質：**它們一定會給你 k 群**，不管群存不存在。把純隨機常態噪音丟進去，K-Means 照樣輸出 4 群、群心互不相同、ANOVA 照樣 p < 0.001（見 §八 S1）。HDBSCAN 是整條階梯上**唯一會說「我找不到密度結構，這些點全是噪音」**的方法。

所以交叉比對不是「用兩個方法看誰比較好」，而是**用一個不預設群數的方法，去檢查另一個預設群數的方法有沒有在無中生有**。

比對用 Adjusted Rand Index，對「隨機一致」做了校正（純隨機分割的期望值為 0，而未校正的 Rand Index 隨機分割會落在 0.5 附近【教材】）：

$$\mathrm{ARI}=\frac{\sum_{ij}\binom{n_{ij}}{2}-\left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right]\big/\binom{n}{2}}
{\tfrac12\left[\sum_i\binom{a_i}{2}+\sum_j\binom{b_j}{2}\right]-\left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right]\big/\binom{n}{2}}$$

計算時**排除 HDBSCAN 的噪音點**（`label = -1`），否則噪音會被當成一個「群」拉低 ARI。噪音佔比另外單獨報。

HDBSCAN 的參數只有一個要調：`min_cluster_size`。**直接綁 §5.3 的可執行性門檻**，不要另外調——

$$\texttt{min\_cluster\_size}=\max\!\left(30,\ \lceil 0.05\,n\rceil\right)\quad\text{【推導，待驗證；與 §5.3 的 (a)(b) 兩條同源】}$$

`min_samples` 預設等於 `min_cluster_size`。**方向不要記反**：`min_samples` 是核心距離取「第幾近鄰」，$\text{core}_k(x)$ 對 `min_samples` 單調遞增 → mutual reachability distance 跟著變大 → 稀疏區的點更難進入任何群，所以**調大＝更保守＝更多噪音，調小＝更少噪音**【推導；已於 sklearn 1.9.0 `sklearn.cluster.HDBSCAN` 上復核：`min_cluster_size` 固定 43，`min_samples` 由 5 調到 80，噪音佔比由 8.9% 單調升到 15.3%】。調整範圍限 $[5,\ \texttt{min\_cluster\_size}]$，每次調整要把調整前後的噪音佔比記進 `cluster_spec.json`——因為 §6.3 的判讀門檻與 §6.2 的四種情況都直接讀這個數字。

教材對 DBSCAN 的啟發式是 $MinPts \ge \log N$ 或 $MinPts = 2d$ 或 $\ge d+1$【教材】，在行銷資料上這三個都太小（$d=5$ 時只有 10）。注意那是 **DBSCAN 的語意**：在 DBSCAN 裡 MinPts 同時決定「核心點」與「群的最小規模」，太小會產生一堆 10 人的碎群；HDBSCAN 的群大小下限是由 `min_cluster_size` 管的，`min_samples` 太小在這裡的後果不是碎群，而是**噪音判得太少、把邊緣點硬塞進群**——一樣過不了可執行性檢驗，只是失效方式不同。

### 6.2 四種判讀結果

| 情況 | ARI | HDBSCAN 有沒有找到群 | 判讀 | **該怎麼辦** |
|---|---|---|---|---|
| **A 一致** | > 0.6【既有規格，出處 `19_圖表與統計表規格.md` §1.4 的 ARI 警戒線】 | 有，群數與 k 接近 | 兩個機制完全不同的方法找到同一批結構 → 可信 | 採用 K-Means 的分群（硬標籤好溝通、每人都有歸屬）。報告寫「HDBSCAN 獨立驗證，ARI = 0.73」。**這是唯一可以把分群當作決策基礎的情況** |
| **B K-Means 有、HDBSCAN 全噪音** | `N/A`（HDBSCAN 只有一群或零群） | 沒有 | **這批資料沒有密度結構。** K-Means 的 4 群是對連續雲的人工切割 | **誠實說明，不要硬拗。** 分群章保留（18-E11），但措辭全面降級：「群」改寫成「分層」，「這是四種顧客」改寫成「這是依 RFM 連續分布做的四段人工切割，段與段之間沒有自然斷點」。下游建議降一級證據等級。同時檢查是否為尺度問題（§3.3） |
| **C HDBSCAN 有、K-Means 沒有** | < 0.3 | 有，且群形狀不規則 | **非球形結構。** K-Means 的球形假設失效（§四 關卡 4） | 升級。按 §2.1 先試 GMM（full covariance，允許橢圓），仍不行就直接採用 HDBSCAN 標籤。報告要**點名**：「HDBSCAN 群 2 在 LN_M–CAI 平面上呈弧形，K-Means 把它切成三塊，客戶 #1729、#2036、#3596 行為幾乎相同卻分屬三群」 |
| **D 部分一致** | 0.3 – 0.6 | 有，但群數不同 | 有結構但邊界對不齊。通常是 1–2 個群穩定、其餘在打架 | **逐群比對，不要整體採用或整體否定。** 做「K-Means 群 × HDBSCAN 群」的交叉表熱圖（§十），對角線清楚的群照常用、糊掉的群合併或標為「邊界不明」。行銷名單只從對角線清楚的群出 |

### 6.3 噪音那 5–10% 怎麼處理

**不要硬塞回最近的群。** HDBSCAN 判為噪音的點，意思是「它周圍的密度不足以構成群」，強行分配等於把「我不知道」偽裝成「我知道」。

| 噪音佔比 | 判讀 | 處理 |
|---|---:|---|
| < 2% | 正常的邊緣點 | 標為 `群99_未分類`，不進任何名單，人數列在群大小表裡 |
| **5–10%** | **典型情況，最需要注意**【推導，待驗證；門檻沿用任務既有慣例】 | **獨立成群**，命名為「未分類／離散型」，並**單獨看一次輪廓**——這批人常常是最有價值或最異常的：批發轉售者、企業採購、機器人帳號、極端高消費 |
| > 20% | 參數或尺度有問題 | 先檢查 §3.3 的 WGSS 貢獻表與維度數。維度 > 8 先降維。仍然 > 20% → 回情況 B 處理 |

噪音群的三個必做動作，缺一不可：

```
① 在群大小表出現，不准從表格消失         —— 「排除了多少」永遠可回查（18-E22）
② 算一次它的五維 High/Med/Low（§九）      —— 常常一眼就看出是批發轉售者還是 bot
③ 在 §八 的卡方表裡有自己一欄             —— 它的人口組成往往與其他群完全不同
✗ 不准做：把噪音分配回最近的群            —— 那是把「我不知道」偽裝成「我知道」
```

## 七、穩定性驗證

### 7.1 為什麼三指標不夠

三指標回答的是「這個 k 的分群品質好不好」，**不回答「換一批人會不會得到同一批群」**。後者才是決策要的：行銷團隊照著群 2 發券，前提是下個月重跑時群 2 還是同一批人。

教材對此完全零覆蓋——`03_clustering_sequence.md` §15 自列缺口：「**分群穩定性／bootstrap 驗證：完全沒有**」【教材自承】。本節是本 skill 補的。

### 7.2 Bootstrap ARI 流程

```
① 從 n 位顧客中有放回抽樣 n 位，得到 bootstrap 樣本 b（b = 1..B，B = 200）
② 對每個 b：用「完全相同」的 pipeline 重跑
      —— 同樣的 log1p 欄位、同樣的 z-score 做法（在 b 內重新 fit）、
         同樣的 k、同樣的 n_init、同樣的 seed 策略
      ✗ 不可以沿用原樣本的 scaler：那會洩漏原樣本的分布，ARI 虛高
③ 把 b 的分群結果映射回原樣本（只比對兩次都出現的顧客）
④ 算 ARI(原分群, b 分群)，得到 B 個 ARI 值
⑤ 報告：中位數、IQR、直方圖（標中位數與 0.6 警戒線，見 ref 19 §1.4）
⑥ 另外算「逐群成員留存率」：某群的成員在 b 中仍被分在一起的比例
```

### 7.3 門檻與降級

| Bootstrap ARI 中位數 | 判定 | 動作 |
|---|---|---|
| **≥ 0.75** | 穩定 | 照常使用。報告寫出中位數與 IQR |
| **0.60 – 0.75** | 可用但要標註【既有規格，0.6 為 ref 19 §1.4 的警戒線】 | 可用，但**逐群看留存率**：留存率 < 0.6 的群，其專屬建議降級為「試點」，不做全量投放 |
| **< 0.60** | 不穩定，**不得作為決策基礎** | 降級。路徑見下 |

不過關時的降級階梯（沿用 `00_通則與紀律.md` §1.6，往「前提更少」的方向退一格）：

```
bootstrap ARI < 0.60
   │
   ▼ ① 先檢查是不是尺度問題（§3.3 的 WGSS 貢獻表）—— 這是最常見的原因，且可修
   │
   ▼ ② 降 k：k-1 重跑。群愈少通常愈穩。跑到 ARI >= 0.60 為止
   │
   ▼ ③ 仍不過 → 退回分位切割（NTILE(5) / 20-60-20）
   │        明寫「這是單變數分層，不是分群」，並在報告寫清楚放棄分群的理由
   │
   ▼ ④ 退到底 → 業務規則標籤（§一）+ 敘述統計，明說「本批資料不支持穩定的顧客區隔」
```

**「改跑兩階段（Ward + K-Means）」不在這條階梯上。** 它的前提是 K-Means 的前提**再加一條** $O(n^2)$ 空間（§二 的 L2；n = 5 萬時光是壓縮距離矩陣就要 $\binom{50000}{2}\times8\ \text{bytes}\approx9.3$ GB，這正是 §2.1 寫「n > 3 萬要先抽樣或改走 L1」的原因）。前提更多不是更少，把它排進降級階梯會違反 §十一「階梯只能在『前提由多到少』的軸上插入，**不可平移**」，也會讓大 n 專案照著降級路徑走進 OOM。

它在 §二 是 **L1 → L2 的升級分支**：seed 不穩（10 個 `random_state` 兩兩 ARI 中位數 < 0.75）時走它，理由是 Ward 的初始群心比隨機 seed 穩定。所以正確用法是——在 ② 之後、③ 之前，**若 n ≤ 3 萬**，先試這條升級路；不合條件或試了仍 < 0.60 才繼續往 ③ 退。

`執行紀錄/degradation_log.md` 的記法：走 ①②③④ 記 `downgrade`，走兩階段那條記 **`upgrade`**（不是 `downgrade` 也不是 `lateral`）。每一次降級都要加一列（七欄格式見 `00_通則與紀律.md` §1.6），並在該章小結複述前四欄。

### 7.4 另一件事：分群「是不是真的」要另外測

bootstrap ARI 測的是**穩定性**，不是**存在性**。純隨機噪音也可能得到穩定的分群（因為切法本身穩定）。要主張「這批資料真的有群結構」，用參考分布【素材建議，出處：`gap-statistical-inference.md` S1 修補動作 2】：

```
scripts/cluster_validity.py
  對「同尺度的參考資料」跑完全相同的 pipeline，B = 200 次：
    參考資料兩種都跑 —— (a) 各欄獨立 permutation 打亂（保留邊際分布、破壞相關結構）
                        (b) uniform hypercube（連邊際分布也不保留）
  比較實際的 CH / gap 與參考分布，輸出 structure_pvalue
  → 這個數字才可以寫進報告當「分群有效性」的依據
  → §八 的 ANOVA p 值不行（見 S1）
```

### 8.1 順序與等第對照（IB5082 HW8 的原始評分階梯）

檢定套組的順序不是品味問題，**它直接對應等第**【實測，出處：`local/大數據行銷IB5082/03_作業題目與評分標準.md` §8.2–8.3，原始評分標準】：

### 8.2 ★ S1：分群輸入變數不准跑 ANOVA（循環推論）

這是整個 M6 最嚴重、也最沒有被任何既有規則攔住的問題【素材建議，出處：`gap-statistical-inference.md` S1，列為 critical】。

**問題**：K-Means／Ward 的目標函數是最小化 WGSS，等價於最大化 $\mathrm{BGSS}/\mathrm{WGSS}$——而單因子 ANOVA 的

$$F=\frac{\mathrm{BGSS}/(k-1)}{\mathrm{WGSS}/(n-k)}$$

**正是那個被最佳化的量**（教材自己在 CH Index 那節寫了同一個式子【教材】）。對分群輸入變數跑 ANOVA，等於用最佳化後的目標函數值去檢定它自己。

**具體代價**【素材原文情境】：100 位客戶，(LN_F, LN_M, CAI) z-score 後跑 Ward，k=4。對四群做 M 的單因子 ANOVA：F(3,96) = 182.4、p < 1e-30，Tukey 六組成對比較全部顯著。報告寫「四群在購買金額上存在極顯著差異（p < 0.001），證實分群結果具備統計效力」，據此把群 1（29 人）定為 VIP，投入 29 × 5,000 = **14.5 萬元**專屬禮遇預算。
**問題在於**：把同一份資料換成純隨機常態噪音（不存在任何真實群結構），跑同一條 pipeline，**一樣會得到 p < 0.001**。這個 p 值對「群是真的」提供**零證據**。

**規則**：

| 變數類型 | 准做什麼 | **禁止做什麼** |
|---|---|---|
| **(a) 分群輸入變數**（`cluster_spec.json` 的 `input_vars`：R/F/M/RFM Score/CAI/CRI/因素分數/LN_F/LN_M） | **只做輪廓描述**：群均值、群內 sd、群大小、index（相對全體＝100，見 §9.1）。表格標題**強制加註**「（分群輸入變數，僅為輪廓描述；分離度證據見 §7.4 的 structure_pvalue）」 | **輸出物件裡不得有 p 值欄位，也不得有 $\eta^2$、$F$、95% CI。** 不跑 ANOVA、不跑事後檢定、不寫「顯著」二字 |
| **(b) 非輸入變數**（人口統計、後續期間的行為、未進分群的獲利指標） | 完整走 §8.3 → §8.4 → §8.5 的檢定套組 | — |

**為什麼連 $\eta^2$ 也禁**【本 skill 對素材的修正，2026-07-27；`gap-statistical-inference.md` S1 修補動作 1 原文是允許報 $\eta^2$ 的，但那道防線擋不住 S1】：$\eta^2=\mathrm{BGSS}/\mathrm{TSS}$ 與被最佳化的 $F$ 是**嚴格單調的一對一變換**——

$$F=\frac{\eta^2}{1-\eta^2}\cdot\frac{n-k}{k-1},\qquad \frac{\mathrm{d}}{\mathrm{d}\eta^2}\!\left[\frac{\eta^2}{1-\eta^2}\right]=\frac{1}{(1-\eta^2)^2}>0$$

而 $n$ 與 $k$ 在 §8.3 的群大小表裡本來就有，所以**報 $\eta^2$ 等同報 $F$，讀者一行算術就能還原 p**。禁 F 的理由（「F 正是那個被最佳化的量」）原封不動適用於 $\eta^2$。實測：對 100×3 純標準常態噪音跑 z-score → K-Means(k=4) 再對第一欄算 $\eta^2$，三次重跑得 0.503 / 0.454 / 0.493，換算回的 $F$ 與 `scipy.stats.f_oneway` 逐位相同、$p\sim10^{-14}$【實測，2026-07-27 於 sklearn 1.9.0 復核】——$\eta^2$ 被同一個機制灌水到「高度區辨」的量級，只是換了個標題。95% CI 同樣不准出：群成員是**照這個變數的值挑出來的**，那是事後選擇區間、覆蓋率不對，而且區間不重疊會被讀成顯著宣稱（16 §1.4 的 p／效果量／CI 三件套格式更會強化這個誤讀）。需要「群分得開不開」的數字時，唯一合法的來源是 §7.4 的 `structure_pvalue`。

**18-E1 的適用範圍要跟著修正**：E1 的「ANOVA → 事後檢定綁定，不可分離」只適用於 **(b) 類變數**。對 (a) 類變數，正確做法是**根本不跑 ANOVA**，因此也沒有事後檢定可漏。

`verify_outputs.py` 的 gate（不通過**不得輸出**）：

```python

    "S1 違規：對分群輸入變數跑了 ANOVA 或報了 η²（η² 與 F 是嚴格單調變換）"

# 血緣比對（§3.1 CRI 列、§8.4 排除條款）：CRI 的先驗群變數算分群輸入的上游
assert set(cluster_input_upstream_vars) & set(chi2_tested_vars) == set(), \

```

> ✅ 這兩道 gate 已實作在 `scripts/verify_outputs.py`，代號 **T08**（ANOVA／η²／F／95% CI）與 **T09**（血緣卡方），不通過退出碼 1。
>
> T08 分兩層查，缺一不可：**(a) 自我宣告層** 比對 `analysis_objects.json` 的 `分群輸入變數` 與登錄的 ANOVA 因變數／η² 變數；**(b) 交付層** 直接掃 `統計表/` 底下真的要交出去的 CSV —— 只驗 (a) 等於只擋「有誠實登錄的人」，沒登錄的照樣交得出去。沒有 `分群輸入變數` 時 gate 會明說「這次沒有驗到」並退 warning，不靜默放行。
>
> 表格若含分群輸入變數但**沒有**推論欄位，T08 另查標題有無本節強制加註的「僅為輪廓描述」字樣，缺了退 warning —— 沒有那句，讀者會把群間差異讀成統計結論。

**「獲利指標」怎麼辦？** IB5082 分析動作 18 原文要求「F 檢定／單因子 ANOVA（獲利指標）」，而獲利指標常常就是 M。解法是**用不同期間的變數**：分群用 `as_of` 之前的 M，檢定用 `as_of` 之後的 M（後續期間的實際消費）。後者不是分群輸入，跑 ANOVA 完全合法，而且商業意涵更強——它回答「這個分群能不能預測未來消費」，而不是「這個分群有沒有按 M 切開」。

### 8.3 第一關：卡方適配度檢定

$H_0$：各群人數比例符合某個期望分布（均等，或母體既有分類的比例）。

$$\chi^2=\sum_{i=1}^{k}\frac{(O_i-E_i)^2}{E_i},\qquad df=k-1$$

商業意涵：如果各群人數顯著偏離均等，代表顧客結構本身是傾斜的（例如 46.3% 集中在一群），這件事本身就要寫進報告——它會直接影響資源配置。

**期望次數 gate**：每一格的 $E_i \ge 5$。任一格 < 5 → 合併相鄰群或改用精確檢定。

### 8.4 第二關：卡方獨立性檢定（人口統計變數）★ 期望次數 gate

這是人口統計變數唯一合法出現的地方（§3.2）。表格規格：所有群 × 所有人口變數都要出現，**不顯著標 `n.s.` 並照樣寫結論**（18-E16／E17；符號沿用 `00_通則與紀律.md` §四）。

**排除條款（血緣污染）**：若分群輸入含 `CRI` 而它的先驗群是用人口變數分的（見 §3.1 CRI 列），**該批先驗人口變數不得進入本節的卡方表**。它們已經透過 CRI 進了分群輸入，再拿它們去檢定這個分群，等於用被污染的分群去檢定污染源——結論會寫成「群 3 以外島男性為主，建議針對該區投放」，而那個關聯是自己造出來的。表註須列出排除了哪幾欄與理由。§8.2 的 gate 只比對變數名稱，攔不到這種衍生血緣，必須人工把關。

**但在跑之前必須過期望次數關**【素材建議，出處：`gap-statistical-inference.md` S5，critical】：

$$E_{ij}=\frac{R_i \cdot C_j}{n}\ \ge 5\quad\text{（全部格子）}$$

**不加這道 gate 的具體代價**【素材原文情境】：100 位客戶分 4 群，群大小 38/29/21/12。對「教育程度」5 個水準做獨立性檢定，$4\times5=20$ 格。群 4（n=12）那一列的期望次數是 0.96 / 2.64 / 3.00 / 4.44 / 0.96——**五格全部 < 5，其中兩格 < 1**；整張表 20 格中有 **9 格 $E<5$（45%）**。`scipy.stats.chi2_contingency` 照樣吐出 $\chi^2=31.2$、df=12、**p = 0.0019**。報告寫「群 4 以研究所以上為主（33.3%，全體僅 8%），建議針對群 4 投放高端財富管理商品」——**但群 4 只有 12 人，研究所以上 4 人**，那個 33.3% 的 95% CI 大約是 [10%, 65%]。行動代價：為 12 個人（其中 4 人）立一條高端商品線，含產品設計、法遵、通路訓練，成本遠超這群人的終身價值。

| 期望次數狀況 | 動作 |
|---|---|
| 全部 $E_{ij}\ge5$ | ✅ 正常跑卡方 |
| 有格子 $E_{ij}<5$ 但 < 20% 的格子 | ⚠️ 合併類別（教育程度 5 級併成 3 級），重算後再跑 |
| ≥ 20% 的格子 $E_{ij}<5$，或任一格 $E_{ij}<1$ | ❌ **卡方禁行**。改 Fisher 精確檢定（2×2）或蒙地卡羅 p 值；再不行就只出**列聯表 + 各格 95% CI**，明寫「樣本不足，不做獨立性檢定」 |

包子自己的報告已經有正確示範：狂刷豹（5 人）的年齡與地區 F 值**整格填 `—`**，因為 5 人全落在同一年齡層同一地區，無法檢定【實測，出處：`gdrive/own/01_包子自己的報告與作業.md` §7.4】。

### 8.5 第三關：F 檢定／ANOVA → 事後檢定（不可分離）

**只對 §8.2 的 (b) 類變數做。** 前提檢查與降級沿用 `05_資料特徵檢驗.md` §1.2：

| Levene（`center='median'`）| 判定 | 走哪條 |
|---|---|---|
| p > 0.05 | 同質 | one-way ANOVA → **Tukey HSD** |
| 0.01 < p ≤ 0.05 且變異數比 < 4 | 邊緣 | **Welch ANOVA** → Games-Howell |
| p ≤ 0.01 或變異數比 ≥ 4 | 不同質 | Welch ANOVA，或轉換後重檢 |
| 各組 n 差異 > 3 倍 且不同質 | 最壞 | **先轉換後重檢；仍不同質走 Welch ANOVA + Games-Howell**。**這一格不可以退到 Kruskal-Wallis**（理由與實測見 05 §1.2） |

**分群後最容易踩到「各組 n 差異 > 3 倍」**——群大小天生不等（包子的報告是 46.3% vs 3.4%，比值 13.6 倍）。所以分群後的 ANOVA 預設就該先看 Levene，不要當例外處理。

**事後檢定是硬性綁定**（18-E1，全班最大扣分群 27 人，A+ → A）。降級階梯：

```
Tukey HSD → Games-Howell → Dunn（BH）→ 手動獨立樣本 t（BH 校正）→ 敘述統計對照表
```

退到最後一格仍然要交出「平均數與變異數敘述性統計」——**有備案並執行仍是 A+**（§8.1）。

三件不可省的附帶要求：① p 值 + 效果量（$\eta^2$ 或 Cohen's d）+ 信賴區間三者並報；② **BH 校正只套在「多個變數各自的 omnibus 檢定 p」這一族**（例如 10 個獲利指標各跑一次 ANOVA，$m=10$），同時列原始 p 與校正後 p（18-G8）。**單一 ANOVA 內的成對比較不再套 BH** —— Tukey HSD／Games-Howell／Dunnett 本身已控制族程錯誤率，再套一次是雙重校正、過度保守（見 10 §8.2 步驟 5）；唯一例外是 Dunn，它的 p 本來就要配 BH。 ③ 放寬 α（分群後 n 小）要在表標題明寫「顯著水準放寬至 α=0.20」並說明理由（18-E18）。**不顯著的列要留在表裡並附 MDE**（18-E16、`00_通則與紀律.md` §四）。

## 九、命名體例

**可直接複製的填空範本在 `templates/群命名體例.md`**（含包子原報告的完整五維表、決策表骨架、樣本太小的三段式處置）。本節只寫判定規則。

### 9.1 四件套與 differential labeling

每一群缺一不可【實測體例，出處：`gdrive/own/01_包子自己的報告與作業.md` §3.3 表 7.2、§8.5】：**① 動物名**（兩到三字，會議上叫得出來）**② High/Medium/Low 五維表 ③ 文字描述**（2–4 句，說行為不說人口）**④ 一句話點評**（口語、有畫面感，例：「時而出沒，金額小，滑個兩下就跑掉。」）。**破格只發生在命名，不發生在論述**——章名一律中性，只有群名可以有人味。

High/Med/Low **不能用群內絕對值切**，要用相對全體的 index。這是教材「Computer 陷阱」的直接對應【教材，出處：`03_clustering_sequence.md` §10.4】：三個群的高頻詞都是 "computer"，因為那是**整體樣本的共同特徵**，不是群的特徵。行銷版本一模一樣——五個群的 top feature 都是「年齡 30–45」「都會區」。

$$\text{index}_{k,j}=\frac{\bar x_{k,j}}{\bar x_{\cdot,j}}\times100
\qquad\text{或標準化版本}\quad z_{k,j}=\frac{\bar x_{k,j}-\bar x_{\cdot,j}}{\mathrm{sd}(x_j)}$$

| index | 標記 | 【推導，待驗證】 |
|---|---|---|
| ≥ 120 | **High** | 相當於 $z\gtrsim +0.5$ 的量級，實務上「明顯偏高」的常見切點 |
| 80 – 120 | Medium | |
| ≤ 80 | **Low** | |

命名只准用 index 明顯偏離 100 的維度。**全部五維都在 80–120 的群沒有特徵**——回 §5.3 第 ③ 步合併掉。

### 9.2 命名驗證規則 ★

> **命名要能讓沒看數字的人猜出這群人的行為。**

可執行的檢查是盲測：遮住五維表，只給群名，問一位沒參與分析的同事三題——「這群人多久買一次？」（對 F/R）、「單次買多貴？」（對 M）、「最近在不在買？」（對 R/CAI）。**答對 ≥ 2 題才算通過。**

答對 ≤ 1 題有兩種可能，處理完全不同：

| 診斷 | 徵狀 | 處理 |
|---|---|---|
| **命名壞** | 五維表確實有明顯特徵，但名字取得抽象（「群 A」「高價值客」「潛力客」） | 重新命名。用 index 最極端的兩個維度造名 |
| **群壞** | 五維表本身全部落在 Medium | **不是命名的問題。** 回 §5.3 第 ③ 步，這一群該被合併 |

命名反面清單、決策表骨架（**建議固定 3 條，第 (3) 條必為統計結果直翻行動**）、以及樣本太小時的「承認 → 降級 → 轉向」三段式，全部見 `templates/群命名體例.md` §四、§六、§七。要記住的一句話：**不刪章節、不刪表格、只降低宣稱強度**（18-E11）。

```
§九 的自我檢查（命名完成後逐條對）
  [ ] 每群都有四件套（動物名 / 五維表 / 文字描述 / 一句話點評）
  [ ] High/Med/Low 用 index 切，不是用群內絕對值
  [ ] 每群至少有 1 個維度 index 偏離 100 超過 20 —— 全 Medium 的群要合併
  [ ] 盲測三題，每群至少答對 2 題
  [ ] 群名不含人口統計詞彙、不與既有會員等級撞名
  [ ] 文字描述說的是行為，不是「30–45 歲都會白領」
  [ ] 每群一張決策表，第 (3) 條建議帶統計依據（跑不出來則明寫降為 2 條）
```

3. **距離度量的選擇沒有獨立一節。** 教材有完整的四距離對照（Euclidean／Manhattan／Cosine／Jaccard）與行銷資料型態的映射，本文預設 Euclidean（因為白名單全是連續行為指標，低維），但「品類佔比用 Cosine」「購買清單用 Jaccard」這條路徑沒有展開。
