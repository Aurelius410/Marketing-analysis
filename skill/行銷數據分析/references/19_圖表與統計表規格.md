### 2.1 為什麼不能直接用現成色盤

實測五組業界最有名的色盲友善盤，在**白底、8 色、對比 ≥3:1 且三種色覺缺陷下最小 ΔE2000 ≥12** 的門檻下，**沒有一組通過**。原封 Okabe-Ito 的問題不在色盲可辨性（deutan ΔE 13.3、protan 12.9 其實很好），而在**白底對比**：

| 色 | hex | 白底對比 | 當線條可見？ |
|---|---|---:|---|
| 檸黃 | `#F0E442` | **1.32** | ❌ 看不見 |
| 琥珀 | `#E69F00` | **2.25** | ❌ |
| 天藍 | `#56B4E9` | **2.31** | ❌ |

深色主題的對應陷阱是 **viridis**：未截斷的低端 `#440154` 對深色背景 `#14181F` 的對比只有 **1.17:1**，整條色階的低端是隱形的。

作法：**保留 Okabe-Ito 的色相邏輯，按對比切兩層 —— 前 5 色可畫線，後 3 色只能填面積。**

## 三、字型

中文**微軟正黑體**、英文 **Times New Roman**、內文 **≥12pt**，其餘等比例放大。

### 3.1 字級階梯（以內文 12pt 為基準）

| 用途 | 大小 | 字重 | 行高 |
|---|---:|---|---:|
| 報告內文 | **12 pt** | 400 | 1.75 |
| 表格內文與數字 | 11 pt | 400 | 1.45 |
| 小字註解／資料來源／口徑註腳 | 9.5 pt | 400 | 1.6 |
| 圖表刻度標籤 | 10 pt | 400 | 1.2 |
| 圖表軸標題 | 11 pt | 400 | 1.3 |
| 圖表標題（結論句） | 13.5 pt | 600 | 1.4 |
| 節標題 / 章標題 | 15 pt / 20 pt | 600 / 400 | 1.4 / 1.3 |
| KPI 主數字 | 30 pt | 600 | 1.1 |
| 投影片標題 / 內文 | 28–32 pt / 18–20 pt | 600 / 400 | 1.25 / 1.5 |

`axes.unicode_minus = False` 必設，否則 matplotlib 用 U+2212 而多數中文字型缺這個 glyph。中英數之間不手動加空格；數字與中文量詞之間加半形空格（`120 萬`、`3 個月`），與符號之間不加（`12.5%`）。

### 3.2 法務規則與判斷流程

**微軟正黑體與 Times New Roman 都是 Windows / Office 隨附授權**：本機產出沒問題，但**對外散布且需嵌入字型時不被授權**。這時自動切 **Noto Sans TC**（SIL OFL 1.1，可嵌入可再散布），並明確提醒使用者換字了。

```
產出物要不要離開這台機器？
├─ 否（本機預覽 / 自己列印）
│    → 中文 Microsoft JhengHei、英文 Times New Roman  ✅ 直接用
│
└─ 是 ─── 需要嵌入字型嗎？（PDF 嵌入 / PPTX 嵌入 / Web @font-face / 送印刷廠）
          │
          ├─ 否（PNG、已點陣化的圖、對方只看螢幕截圖）
          │    → 維持 JhengHei + Times New Roman ✅
          │      但提醒：對方機器若無此字型，HTML 互動圖會 fallback
          │
          └─ 是
               → 中文切 Noto Sans TC（OFL）；襯線需求切 Noto Serif / Source Serif 4
               → ⚠️ 主動告知：「這份要對外，字型已從微軟正黑體換成 Noto Sans TC
                  （授權原因），版面寬度會有微幅變化」
               → ⚠️ 數字欄禁用 Noto Serif TC（實測數字有 6 種寬度，非等寬）
```

兩條實測限制（`research/04_design_system.md` §2.3）：

- **matplotlib 對可變字型不做 instancing**。本機 `NotoSansTC-VF.ttf` 只被註冊為 weight=100 一筆，`findfont(weight='bold')` 回傳同一個檔案 —— 渲染「營收 2026」22pt 後 normal 與 bold **逐位元組完全相同**（墨水像素都是 2,121）。要中文粗體只有兩條路：裝 Noto Sans TC 靜態字重 OTF（七字重），或本機產出改用 Microsoft JhengHei（三個實體字重，bold/normal 墨水比 1.233）。
- **`font-variant-numeric: tabular-nums` 對 Noto 與正黑體是無效宣告**（GSUB/GPOS 都沒有 `tnum` feature，18-T10）。幸好 Noto Sans TC 預設就等寬（0.521 em）、JhengHei 也等寬（0.5796 em）；但 **Noto Serif TC 宣告了也救不回來**。

### 3.3 三條渲染路徑（機制不同，要分開處理）

| 路徑 | 字型從哪來 | 失敗長什麼樣 | 處置 |
|---|---|---|---|
| **HTML 互動圖**（Altair/Vega-Lite 在瀏覽器） | **收件人的機器** | 靜默 fallback → 版面跑掉、行高變、標籤重疊 | 對外一律 `@font-face` 內嵌 Noto Sans TC subset，不依賴收件人 |
| **PNG → pptx**（vl-convert / matplotlib） | **產圖的機器（我們自己）** | **豆腐字 □□□，靜默失敗** —— 圖產出來了、檔案大小正常、沒有 warning | 產圖前**必跑字型檢查**，產圖後抽驗一張肉眼確認；CI/容器先裝字型或 `vl_convert.register_font_directory` |

### 4.3 明確禁用規則（寫成 lint，不是提醒）

| 規則 | 門檻 | 為什麼（不是品味問題） |
|---|---|---|

| **文字雲** | 全禁 | 字級對應詞頻但**面積非線性**、排版隨機、兩張圖無法比較、長詞天生佔優勢。沒有分析價值（SKILL.md 明列） |

### 5.2 空值：三種情況、兩種符號、絕不留白

| 情況 | 填什麼 | 例子 |
|---|---|---|

### 5.3 數字格式速查

| 對象 | 格式 | 實例 |
|---|---|---|
| **相關係數** | **4 位小數** | `0.8847`、`0.5349` |
| **因素載荷** | **3 位小數**，>0.4 黃底標註 | `-0.847`、`0.740` |
| Eigenvalue／變異量／卡方值／CRI／CAI | 3 位小數 | `6.483`、`29.850`、`4.097` |
| **F 值** | **2 位小數** | `5.73`、`0.74` |
| **p 值** | **3 位小數、放括號、與統計量上下兩行同格**；極小值寫 `<.001` | `5.73` 換行 `(0.002)` |
| 事後檢定均值差異 | 5 位小數 + 顯著標 `*` | `1.06815*` |
| 迴歸係數 | 3 位小數 | `0.482` |
| 百分比（正文） | 整數或 1 位小數 | `61%`、`24.5%` |
| 百分比（表格） | **2 位小數** | `32.50%`、`10.50%` |
| 百分比變化 | **正號必須顯示** | `+12.3%`、`−4.5%` |
| **千分位** | **正文加、表格不加** | 正文 `共計 3,077 筆`；表格 `424905`、`13630` |
| 年份／ID 欄 | 永遠不加千分位 | `2026`、`13687` |
| 單位 | 放**欄標頭**，不放每格 | `營收 (千元)`，不是每格「1,234 千元」 |
| 極大數字 | 統一縮放到**欄層級**，不每格自適應 | 禁止 `1.2M` / `340K` 混排 |
| 負數 | `−1,234`（U+2212）或 `(1,234)`，擇一貫徹全篇 | 分析報告用負號、財務報表用括號 |
| 日期區間 | 中文全寫 | `2006 年 1 月 1 日至 2007 年 12 月 31 日` |
| 同欄小數位數 | **固定**，不准這格 2 位那格 3 位 | |

**「報告用/」只准 copy，不准重跑產圖程式碼。** 理由不是省時間 —— 重畫會造成**報告裡的圖與分析時的圖不一致**：資料更新過、隨機種子不同、winsorize 界重算過、色盤改過，任一項都會讓兩張「同一張圖」對不上。一旦不一致就掉進 18-E7 那個最貴的坑：圖例寫「女 75.20%」、內文寫「女性佔 24.8%」，讀者看得出來、助教也看得出來。

```python
# scripts/collect_figures.py —— 唯一允許把圖放進「報告用/」的方式
import shutil, hashlib, json
from pathlib import Path

def collect(fig_paths: list[Path], dest: Path, manifest: Path) -> None:
    """複製而非重畫。同時記錄雜湊，讓 verify_outputs.py 能驗一致性。"""
    dest.mkdir(parents=True, exist_ok=True)
    rec = {}
    for p in fig_paths:
        assert p.exists() and p.stat().st_size > 0, f"圖檔不存在或為 0 bytes：{p}"
        shutil.copy2(p, dest / p.name)      # copy2 保留 mtime，方便比對
        rec[p.name] = {"src": str(p),
                       "sha256": hashlib.sha256(p.read_bytes()).hexdigest(),
                       "bytes": p.stat().st_size}
    manifest.write_text(json.dumps(rec, ensure_ascii=False, indent=2), encoding="utf-8")

# verify_outputs.py 的對應檢查：
#   1. 報告用/ 每張圖的 sha256 必須等於 manifest 中來源圖的 sha256
#   2. 報告 HTML/docx 引用的每個檔名都存在於 manifest
#   3. manifest 中每張圖都有對應的計算結果物件（防手打數字，18-E7）
#   4. 所有圖檔非 0 bytes
```

def palette(n: int, mode: str = "light", *, fill: bool = False) -> list[str]:
    safe  = CAT_LIGHT if mode == "light" else CAT_DARK

## 八、維護條款

| 觸發 | 要做什麼 |
|---|---|
| 新增模組或子分析 | 回 §一補「圖清單 + 表清單 + 每張表結論欄寫什麼」，同步更新 `REQUIRED_FIGURES` |
| 改任何一個 hex | **先跑 `palette_lab.py`**，把新的對比與三種 CVD 下的 ΔE 貼進 §二；正向與負向測試都要重跑 |
| 換字型／換機器／升 matplotlib | 重跑 `check_fonts.py`。§3.2 的可變字型與 `tnum` 兩條結論都是**本機實測值**，換環境就失效，要重測不是照抄 |
| 新增禁用圖種 | 進 §4.3 表，且**必須寫出「為什麼不是品味問題」** —— 寫不出機制性理由就不要禁 |
| 包子改了表格習慣 | 更新 §五，**保留舊寫法作為向後相容說明**並註明日期，不要默默改掉 |
| 交付通路增加（例如加 Quarto／PDF） | §3.3 的三條渲染路徑要變四條，字型行為要各自實測 |

更新時要注意三件事：

1. **不要與 18 重複，要交叉引用。** 這份講「該長什麼樣」，18 講「錯了會怎樣」。新增條目先搜 18 有無對應的 E/G/T，有就寫「見 18-Exx」；若該條有實證代價，**應優先加進 18 而不是加在這裡**。
2. **每個數字都要能追回出處。** 對比 5.19、ΔE 13.2、n=5 上限、相關係數 4 位小數 —— 分別來自本機驗證器計算、prefix 實測表、包子既有報告。新增門檻沒有出處就標「這是設計決定，非引用值」，不要假裝有依據。
3. **色彩門檻中最主觀的一個是 ΔE ≥ 12。** 「ΔE > 10 為明顯不同色」是常見經驗值，12 是安全邊際，**目前查不到針對「資料視覺化類別色最小色差」的正式標準**。若找到權威依據應據以修正，並重跑 §2.3 全部測試 —— 這個數字一動，5 色與 7 色的上限都可能跟著動。
