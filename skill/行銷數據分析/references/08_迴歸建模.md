# 迴歸建模

這份文件負責 **M7**，是整套 skill 裡唯一會產出「係數」的模組 —— 也就是唯一會被主管直接拿去乘上預算的東西。分群給的是名單，迴歸給的是**單位效果**：「客單價每多 100 元，回購機率變多少」「這個通路每多投一萬，訂單多幾筆」。名單錯了頂多發錯 DM，係數錯了會直接錯配預算。

這裡最危險的不是「跑不出來」，而是**跑得出來、報表漂亮、數字錯的**三種情況：計數資料硬套 Poisson（標準誤低估兩倍，一半的「顯著通路」是假的）、`anova_lm(typ=3)` 配預設編碼（主效果平方和實測差近一倍，**不報錯**，見 18-T3）、log-OLS 的預測值直接 `exp` 回去（系統性低估，課程資料集實測少算 64%，見 ref 06 §二）。這三個都不會有任何一條檢定告訴你出事了。

M7 是**選做**模組。沒有可辯護的應變數就不要做（見 00 §五），停在描述與分群比硬湊一個 Y 誠實得多。這份文件的另一半價值在於把 MBA5045 那套 R 流程**一比一搬成 Python** —— 抄漏一行就翻錯一個功能，所以對照表逐條標了本機實測狀態。

## 一、依 Y 的型態選模型族

**第一件事永遠是看 Y，不是看 X。** 教材的分類地圖（MBA5045 1007 §7）只分四格：Y 連續 → LM／ANCOVA／ANOVA，Y 類別 → GLM。這對行銷資料不夠用，因為行銷的 Y 有一半是**計數**與**含 0 的金額**，教材那張表把它們全歸進「GLM」就不管了。

下面這張表是操作版。**「怎麼判斷該用它」那一欄是硬性的**：判斷沒做就選模型，等於猜。

| Y 的型態 | 模型族 | 怎麼判斷該用它（要真的算） | Python |
|---|---|---|---|
| 連續、近常態 | **OLS** | 偏度 \|skew\| < 1；殘差三圖過關（ref 05 §1.1） | `smf.ols` |
| 連續、右偏、恆正 | **Gamma GLM + log link** | 偏度 > 1 且 min(Y) > 0；Var 隨 Mean 超線性上升 | `sm.families.Gamma(links.Log())` |
| 二元 0/1 | **Logistic** | Y 只有兩個值；EPV = 少數類事件數 ÷ 參數數 ≥ 10（ref 05 §1.9） | `smf.logit` / `smf.glm(...Binomial())` |
| 比例（整數分子/分母） | **Binomial GLM（分組）** | 有 $m_i$ 與 $s_i$ 兩欄。**連續型比例（濃度、成長率）不可用** | `glm` + `cbind` 等價寫法 |
| 計數 | **Negative Binomial（不是 Poisson）** | $\hat\psi=\dfrac{\text{Residual Deviance}}{\mathrm{df}_{\text{resid}}} > 1$，或快篩 $s^2 \gg \bar x$ | `sm.NegativeBinomialP` |
| 大量 0 + 少數正計數 | **Hurdle 或 ZINB** | 零佔比 > 30%（ref 05 §1.7）。**先判斷零的來源** | `HurdleCountModel` / `ZeroInflatedNegativeBinomialP` |
| 金額，含 0 的連續值 | **Tweedie（複合 Poisson-Gamma）** | Y ≥ 0、有一坨 0 + 右偏正值，且 Y 不是整數 | `sm.families.Tweedie(var_power=1.5)` |
| 流失「時間」 | **Kaplan-Meier + Cox** | 有右設限（觀察期結束時還沒流失的人） | `lifelines.CoxPHFitter` |
| 同顧客多期／同門市多月 | **混合效果（隨機截距）** | ICC > 0.20（ref 05 §1.3） | `smf.mixedlm(..., groups=)` |
| 有序類別（滿意度 1–5、等級） | **Ordinal Logistic** | 類別有序且間距不等距，不可當連續 | `OrderedModel` |

### 1.1 為什麼行銷計數幾乎必然是 Negative Binomial

Poisson 的公設是 **Mean = Variance**。行銷計數三個結構性原因讓這條必定破（出處：MBA5045 `02_logistic_glm_categorical.md` §3.8「不獨立／機率不同質／模型不足」三條）：

- **不獨立** —— 同一個廣告組內的使用者互相影響（社群擴散、同戶共用帳號）。
- **機率不同質** —— 同一個分眾裡，重度用戶與輕度用戶的真實購買率天差地遠。
- **模型不足** —— 競品活動、季節、天氣永遠沒放進去。

硬跑 Poisson 的後果，教材寫得非常直接（同上 §4.7）：**係數本身大致不偏（趨勢線沒畫錯），但標準誤被嚴重低估，p 值太小、信賴區間太窄，型一錯誤增加。**

具體代價（【推導，待驗證】—— 算式為真，數字是為說明而設的典型量級）：某通路月訂單數 $\bar x = 2.4$、$s^2 = 11.5$，則 $\hat\psi \approx 11.5/2.4 = 4.79$，標準誤被低估 $\sqrt{4.79} = 2.19$ 倍。一個真實 $z = 1.0$（完全不顯著）的通路係數，在 Poisson 下會印出 $z = 2.19$、$p = 0.029$ —— **報告會寫「該通路顯著提升訂單數」，預算就配過去了**。這正是 18-G6 的統計版本：不是相關被寫成因果，是雜訊被寫成訊號。

**所以預設走 NB，Poisson 只在 $\hat\psi \approx 1$ 且你真的檢查過的時候用。** 順序不可顛倒（出處：同 digest §3.8）：Deviance 太大時，先查（1）漏變數／非線性 →（2）少數幾筆殘差撐大整體 →（3）都排除後才歸因 overdispersion。

### 1.2 大量零：先判斷零的來源，再選模型

**這一步比選模型重要。** 零的來源決定模型族，選錯會把「不可能買的人」跟「這期沒買的人」混在一起估同一組係數：

| 零的來源 | 行銷例子 | 處置 |
|---|---|---|
| **結構零**（根本不可能） | 未開通該服務的會員，該品類次數必為 0 | **從母體排除，不建模**。留著等於用一批不可能有 Y 的人稀釋係數 |
| **抽樣零**（可能買但這期沒買） | 活躍會員本月未購買 | **Hurdle**：兩段獨立估計「買不買」× 「買了買多少」 |
| **混合且分不開** | 名單來源不清的沉睡會員 | **ZINB** |
| **連續型的零 + 右偏正值** | 顧客期間內消費金額（很多人 0 元，其餘右偏） | **Tweedie**，保險與 CLV 的標準做法 |

（門檻與這張表的來源：ref 05 §1.7，該節同時是 M2 發通行證的地方 —— **M7 不重跑這個判斷，直接讀 M2 的特徵檢驗總表**。）

Hurdle 的商業價值在於兩段係數可以不同號：簡訊頻率對「要不要買」是正的、對「買多少」是負的（催得太勤的人買得急且買得少），一個 NB 只會給你一個混合後的、方向不明的係數。

## 三、`anova_lm(typ=3)` 的靜默錯誤 ★

**這是本模組唯一一條「不照做就一定錯」的規則**，也是 SKILL.md 負面清單裡點名的那一條（見 18-T3）。

`anova_lm(typ=3)` 搭配 patsy 預設的 **treatment coding**，會算出**沒有意義的主效果平方和**，而且不拋任何警告。實測（同一份資料，真值：a 有強主效果、b 有主效果、無交互）【實測，出處 `research/02_marketing_models_and_stats.md` §A.3】：

| 項 | 錯誤寫法 `C(a)*C(b)` 的 SS | 正確寫法 `C(a,Sum)*C(b,Sum)` 的 SS | 差距 |
|---|---:|---:|---|
| Intercept | 0.2977 | 103.3492 | — |
| a（主效果） | **179.7631** | **325.6416** | **少算 45%（差近一倍）** |
| b（主效果） | **23.9495** | **48.6390** | **少算 51%** |
| a:b（交互） | 1.4607 | 1.4607 | 相同 |

**最高階交互項的 SS 在三種 Type 下都一樣**（1.4607），所以「交互項看起來對」不能拿來當自我安慰 —— 錯的正好是你要拿去講故事的主效果。

這與 R 完全同構（R 裡不先 `options(contrasts=c("contr.sum","contr.poly"))` 就跑 `car::Anova(type=3)` 也是錯的），差別在 **R 有 `car` 會提醒你，Python 沒有任何東西會提醒你**。

**硬規則**：

1. **預設用 Type II**（`typ=2`）。無交互作用時檢定力最高，且不受編碼方式影響。
2. 只有在期刊／客戶指名 Type III 時才用，**且一律走 `anova3()`**，不准直接呼叫 `anova_lm(typ=3)`。（`scripts/stats_utils.py` 尚未實作 —— 見 §二的 ⚠️ 說明；在它寫出來之前，直接把下方的 `anova3()` 實作貼進分析腳本，規則不變。）
3. 每個 ANOVA 都要接事後檢定（18-E1 綁定，不可分離）。平方和要通過雙路徑驗算 $SS_{between}+SS_{within}=SS_{total}$，容差 $10^{-6}$（見 00 §1.3 的表）。

```python
# scripts/stats_utils.py（規格，檔案待實作）—— 防呆版 Type III，等同 R car::Anova(type=3) + contr.sum
import re
import statsmodels.formula.api as smf
from statsmodels.stats.anova import anova_lm

def anova3(formula: str, data):
    """強制 Sum coding 的 Type III ANOVA。直接呼叫 anova_lm(typ=3) 會靜默算錯（18-T3）。"""
    f = re.sub(r"C\((\w+)\)", r"C(\1, Sum)", formula)
    if "C(" in formula and "Sum" not in f:
        raise ValueError("類別變數必須以 C(x) 標註才能自動轉 Sum coding")
    return anova_lm(smf.ols(f, data, missing="drop").fit(), typ=3)

# 交付前檢查（併入 verify_outputs.py）：
```

## 四、診斷的執行順序

順序來自 MBA5045，且有三處互相印證（出處：`notion/商管統計資料分析/01_eda_regression_anova.md` §4.0 與 §13.2 —— 0923「實務上的快速流程」原文、0923 影響點章節的敘述順序、0923 R code 的實際排列順序 `rstandard()` → `hatvalues()` → `cooks.distance()`）。ref 05 §7.1 已列同一張表，**兩處必須保持一致**；05 管的是模型前的資料特徵，08 管的是模型後的診斷。

**Step 1 一定在 Step 2–4 之前** —— studentized residual 只有在四大假設成立下才近似 $\mathcal N(0,1)$，假設沒過，$|r| > 3$ 這條線本身就沒有意義。

| Step | 做什麼 | 看什麼 | 什麼算有問題 | 有問題怎麼辦 |
|:--:|---|---|---|---|
| **0** | Global F | $F=\dfrac{SSR/k}{SSE/(n-k-1)}$ | $p \ge \alpha$ | 回頭檢查資料或**重新定義 Y**。不要往下跑。$F$ 顯著 ≠ 模型好用 |
| **1** | 殘差三圖 | 見 §五 | 漏斗／弓形／波浪／整體偏移 | 見 §五各自的處方 |
| **2** | 離群值（Y 方向） | `rstandard()` | $\lvert r\rvert > 3$（兩尾機率 < 0.002） | 查四類成因（下表），**不是直接刪** |
| **3** | 槓桿值（X 方向） | `hatvalues()` | $h > \dfrac{3(k+1)}{n}$ 需檢查；$\dfrac{2(k+1)}{n} \le h \le \dfrac{3(k+1)}{n}$ 為灰帶（下界的用法見表下說明） | 敏感度分析 |
| **4** | 影響點（綜合） | `cooks.distance()` | $D \ge 1$ 強警訊；$0.5 \le D < 1$ 留意 | **僅作為模型警訊**，不是刪除依據 |
| **5** | 共線性 | `pairs`/`cor` → VIF | $\mathrm{VIF} > 10$；嚴管產業（電力／通訊／金融）$> 5$ | 見 §六階梯 |
| **6** | 變數選擇 | Testing-based → Criterion-based | — | 見 §七 |
| **7** | 敏感度分析 | 移除可疑點重估 | 係數／SE／$R^2$ **實質改變** | 顯著影響 → 回成因處理；未顯著 → **紀錄即可，通常保留** |

門檻出處：$\lvert r\rvert>3$、$3(k+1)/n$、$2(k+1)/n$、$D\ge1$／$0.5$、VIF 10／5 全部來自 MBA5045 §13.9 公式速查卡與 0923 講義正文。$4/n$ 是 0930 實戰腳本加的業界常用線，**三條都畫，但主判準用 1.0 / 0.5**。

> **表註：$h$ 的下界不是判準。** 講義另有一條「$h < 2(k+1)/n$ → 該點很孤立，也需進一步檢查」（原文見 `notion/商管統計資料分析/01_eda_regression_anova.md` §4.6；該處【評註】已註明：「第二條『$h$ 小於下界也要檢查』是這份筆記獨有的說法（一般教科書只講上界），轉 Python 時建議兩條門檻線都畫」）。**而且它給的理由是反的**：帽子矩陣對角元 $h_i=\dfrac1n+\dfrac{(x_i-\bar x)'S^{-1}(x_i-\bar x)}{n-1}$，在 $X$ 的重心取最小值 $1/n$，離重心越遠越大，且 $\sum_i h_i=k+1$、平均恰為 $(k+1)/n$。所以 $h$ 小代表該點落在 $X$ 的正中央，是**最不孤立**的位置；$X$ 空間的孤立點對應的是 $h$ **大**。實測（$n=148$、$k=5$ 的模擬，與 HOMES4a 同尺寸）：$\sum h_i=6.000$、$\bar h=0.04054=(k+1)/n$、$\min h\approx 1/n$，$h$ 與到 $X$ 重心的馬氏距離相關 $+0.98$；刻意植入一個離重心 8 個標準差的點，其 $h=0.70$，遠在 $3(k+1)/n=0.122$ **之上**而非下界之下；同時 96% 的樣本落在 $2(k+1)/n$ 以下 —— 拿下界當判準等於把幾乎整份資料丟進敏感度分析。**本 skill 兩條線都畫（下界只作圖上參考線），判定一律只用上界**，§4.1 的 HOMES4a 實例與 `templates/迴歸建模_程式範本.py` 的 `is_leverage` 旗標都是這樣算的。

**教材原文的關鍵判讀原則**（0923 §4.4）：「殘差大 ≠ 影響一定大；槓桿高 ≠ 影響一定大。**殘差大 + 槓桿高 = 最危險，但仍需視庫克距離而定。**」

## 五、殘差圖的判讀規則

四種形狀對應四種違反，出處 MBA5045 0909／0916 §4.1（教材原文），與 ref 05 §7.2 同一張表。**這一節是整份文件裡最該印出來貼在螢幕旁的。**

| 圖上看到 | 違反的假設 | 為什麼 | 處方 | 行銷場景的翻譯 |
|---|---|---|---|---|
| **漏斗形**（左窄右寬或相反） | 同質變異 | 誤差變異隨 $X$ 或 $\hat Y$ 改變 | **對數或平方根轉換** → WLS → robust SE（HC3） | 「大客戶的預測誤差比小客戶大得多」→ 直接對 $\log(\text{營收})$ 建模 |
| **弓形** | 同質變異／線性 | 誤差隨 $X$ 系統性增減 | 同上；並檢查是不是漏了 $X^2$ | 廣告費的遞減報酬沒被建模 |
| **波浪狀／週期性** | 獨立性（自我相關） | 誤差跨期相關 | Durbin-Watson 檢查 → Newey-West SE → ARIMA | 週資料的 7 期週期；DW 只測 lag-1 抓不到，要配 ACF 圖 |
| **整體偏上或偏下** | 零均值 | 模型有系統性偏差 | 檢查是否漏了關鍵變數或截距設定 | 只放線上通路、漏掉線下營收 |
| 點雲上下對稱、寬度均勻、無模式 | — | 理想 | ✅ | — |

**Histogram 與 Q-Q plot 只管常態性**，兩者判準不同（0909 §4.2–4.3）：Histogram 理想是鐘形、對稱、中心在 0，問題訊號是偏斜／扁平／尖峰；Q-Q plot 理想是點落在 45 度線，尾端翹起／下垂 = 肥尾瘦尾，整體彎曲 = 偏態。**Q-Q plot 比 Histogram 敏感**，兩張都要畫。

**一個必須先排除的誤判**（出處：`02_logistic_glm_categorical.md` §5.6 F5）：Poisson 模型若 $\hat\mu < 5$，Q-Q plot 本來就會很醜 —— 那是資料稀疏的正常現象，不是模型爛，**沒必要誤殺模型**。同理，未分組的二元 logistic 的 Q-Q plot 會出現兩條曲線，這張圖對它**根本沒有意義**，不要畫也不要解讀。

```
   │                  ③ 不要用轉換去修獨立性，修不了
```

## 六、共線性處理階梯

出處 MBA5045 0923 §5.2（教材原文六條），順序不可跳 —— **前面的成本低、資訊損失小**。

```
1. 收集更多彼此相關性較低的資料
     最理想，實務上常做不到。但這一條要「明寫做不到的理由」，不是跳過
2. 合成變數：把高度相關的指標做成組合指標
     ※ 需要有情境意義。沒有合理解釋時不要硬合
3. 轉換變數：重塑成更細緻的變數（需專業知識輔助）
4. 在理論允許下，移除高度重疊的其中一個
     ※ 最常見也最實務。保留「較有理論意義」或「較容易量測」的那個
5. 多項式／交互項造成的共線性 → 標準化（中心化）可明顯緩解
     ※ 但對「兩個量測幾乎等價」的相關，標準化沒有用 —— 這是教材明列的例外
--------------------------------------------------------------
不要太執著於零共線性。VIF 高 ≠ 模型不可用，需依領域知識判斷並小心解釋
```

**第 2 條的教材實證**（0923 AUTO 資料，$Y=\ln(\text{price})$）：原模型 $R^2 = 0.7005$，但 $1/X_2$（城市油耗倒數）$p = 0.19655$、$1/X_3$（高速油耗倒數）$p = 0.05253$ **兩個都不顯著**；把兩者取平均再取倒數後，$R^2 = 0.7003$（幾乎沒變），該項 $p = 1.95\times10^{-8}$ **變得高度顯著**。這正是「整體 F 顯著但個別 t 都不顯著」的標準徵狀。

**行銷版的同一件事**：電視廣告與數位廣告同期投放（高度相關）→ 模型說兩個都不顯著 → **如果據此砍掉數位預算，是嚴重誤判**。正確處置是走第 2 條（合成「總曝光」）或第 4 條（保留較易量測的那個），並在報告寫明「本模型無法拆分兩通路的個別貢獻，要拆需走 M12 的地理實驗」。

**VIF 高不等於不能用**，通行證是有條件的（門檻與分工出處：ref 05 §1.4）：

| VIF | 預測用途 | 係數解讀用途 |
|---|:--:|---|
| < 5 | ✅ | ✅ |
| 5 – 10 | ✅ | ⚠️ 標準誤已膨脹 $\sqrt{\mathrm{VIF}}$ 倍，報告須註明 |
| > 10 | ✅ **預測不受影響** | ❌ **禁止解讀個別係數的大小與符號** |
| = ∞ 或 > 1000 | ❌ | **這不是共線性，是欄位重複或 dummy trap**，回 M1 查 |

## 七、變數選擇

**兩段式，順序固定**：Testing-based 先篩 → Criterion-based 驗證收尾。教材的實務步驟寫得很明確（0916 §3.9C）：**先用 Individual t-test 挑出「疑似多餘」的變數，再用 Nested Partial F-test 成組確認**，因為共線性會讓變數在邊際上彼此搶解釋力 —— **單一 t 不顯著時，Partial F 仍可能顯著**。

$$\text{Partial } F=\frac{(SSE_R-SSE_C)/(k-r)}{SSE_C/(n-k-1)} \sim F_{k-r,\;n-k-1}$$

前置條件三條，缺一不可做（0916 §3.9B）：縮減模型必須是完整模型把某些係數設 0 的特例（**巢狀**）；兩個模型用同一個 Y 與同一筆資料；**必然 $SSE_R \ge SSE_C$**（不成立就是資料或程式錯了）。單一新增變數時 $F = t^2$。

**三角驗證法則**（0916 §3.9B，教材原文）—— 三者一致才下結論：

| Partial F | 決策 | 應同時看到 |
|---|---|---|
| 顯著 | 保留那批變數（完整模型） | Adjusted $R^2 \uparrow$、$\hat\sigma \downarrow$ |
| n.s. | 移除那批變數（縮減模型） | Adjusted $R^2 \downarrow$ 或幾乎不變、$\hat\sigma$ 不降 |

Criterion-based 收尾用 **AIC**，**判讀只看差值，不看絕對值**（門檻出處：MBA5045 §13.9 公式速查卡）：

| $\Delta\mathrm{AIC}$ | 判讀 | 該怎麼選 |
|---|---|---|
| $\le 2$ | 兩個模型幾乎一樣好 | **選簡單的那個**（變數少、易解釋、資料好收集） |
| 4 – 7 | 較低者有弱優勢 | 選較低者，但在報告列出替代模型 |
| $\ge 10$ | 較低者幾乎可以肯定較佳 | 選較低者 |

### 7.1 「變數被移除」的正確說法（這條是措辭紀律，不是統計）

教材對此有一整組原文（出處：`02_logistic_glm_categorical.md` §5.4 D1–D8），行銷報告最容易在這裡出事：

- ✅ 「**在已納入的其他變數之上，Parking 沒有額外解釋力**」
- ❌ 「Parking 對房價沒有影響」
- 「被刪掉的變數未必與 Y 無關，可能只是關聯性較弱。」
- 「先選變數後再看 p-value，會有**選後 p-value 偏樂觀**的問題。」
- 「刪掉不顯著的變數，通常會讓留下的變數看起來更顯著（標準誤變小、共線性下降），**容易高估其重要性**。」
- 「變數選擇程序**只是參考用**，不保證與最終目標一致。僅供參考，不當作結論本身。」

**行銷版的代價**：stepwise 把「電子報開信率」踢掉 → 報告寫「電子報無效」→ 團隊砍掉電子報預算。實際上它只是與「近 30 天登入次數」高度相關，被後者吸走解釋力。正確的一句話是「在已納入登入行為之後，開信率沒有額外解釋力 —— **這不代表停發電子報不會影響登入行為**」。

不顯著的變數要列表、要寫商業意涵（18-E16），且**同列必須附 MDE**（見 00 §四）。表格空格一律用 `n.s.`（不顯著）／`N/A`（算不出來）／`—`（無樣本），不准留白。

```python

# Criterion-based 收尾：ΔAIC ≤ 2 一律選簡單的
# 並且一定要跑一次 Partial F 對照。兩者結論不一致時**以 Partial F 為準** —— 它有明確的 H0，AIC 沒有
```

## 八、分群後建迴歸的兩種做法

M6 分完群之後最常見的下一句是「不同客群對價格的敏感度不同」。**這句話有兩種做法，只有一種能檢定它。**

| | (A) 各群分開建迴歸 | (B) 全樣本 + 群虛擬變數與交互項 |
|---|---|---|
| 模型 | 群 1：`y ~ x`；群 2：`y ~ x`；… | `y ~ x * C(seg)` |
| β 可以隨群變動 | ✅ | ✅ |
| **可以檢定群間斜率是否真的不同** | ❌ **不行** | ✅ 交互項的 Partial F |
| $R^2$ 可以互相比較 | ❌ **不行** | ✅（同一筆資料、巢狀） |
| 樣本效率 | 差（每群各自估 $\sigma^2$） | 好（共用誤差變異） |
| 小群 | 群 n 小時係數不穩 | 借力大群的誤差估計，較穩 |
| 什麼時候用 | 各群的**變數集合根本不同**時（B2B 群有「合約年限」、B2C 沒有） | **預設走這條** |

教材對此有極明確的立場（0923 §8.5「重點提醒」原文）：

> 「要分析同一資料集中的不同類別資料時，**不可以直接拿各類別的 SLR 來比**，應該放在同一個模型中，並檢驗交互項的顯著性。」

理由有兩層：**（1）** 兩群資料的分散程度與平均值不同，$R^2$ 的基準不同，「拿來比較就像用兩把不同刻度的尺量身高再比誰高」；**（2）** 兩個分開的 SLR **不是巢狀模型、也不在同一筆資料上**，所以根本沒有任何檢定可以比較它們孰優孰劣。

**硬規則：要主張「不同客群敏感度不同」，必須用 (B) 或混合效果，不准用 (A) 的兩個係數大小去講故事。**

還要接住兩件事：**階層性原則**（0923 §9.4）—— 保留交互項就必須保留主效應，不可以只留 `x:C(seg)` 而砍掉 `C(seg)`；**參考組的選擇**（0923 §8.7）—— 基準組選錯會讓所有群看起來都「沒差異」，報表給主管前要自檢，行銷情境的預設基準組應該是**人數最多的群或現行主打客群**，不是字母序第一個。

```python
# (B) 正確做法：全樣本 + 交互項，並檢定「斜率是否真的隨群變動」
from templates.迴歸建模_程式範本 import segment_slope_test

r = segment_slope_test("arpu", "discount_rate", "seg", df, ref="S2")   # ref = 人數最多的群
# H0：所有交互項係數 = 0
# p <  α → 各群斜率確實不同，主效果的解讀必須條件化（不可再講「整體平均效果」）
# p >= α → 沒有證據支持「各群敏感度不同」。用 r["m_parallel"]，並在報告寫明這一句

# 同顧客多期時，(B) 還不夠 —— 觀測不獨立。ICC > 0.20 時改混合效果（ref 05 §1.3）
m_mix = smf.mixedlm("arpu ~ discount_rate * C(seg)", df, groups=df["cust_id"]).fit()
# 交叉隨機效果與多重隨機斜率 statsmodels 支援很差，需要那個就退 cluster-robust SE 並說明
```

## 九、降級路徑

原則沿用 00 §1.6：**沒跑出來不是理由，沒有備案才是。** 降級要點名壞掉的是哪一條前提、帶檢定名稱與數值，不准寫「資料不符合假設」。每次降級在 `執行紀錄/degradation_log.md` 加一列。

```
OLS 的假設嚴重違反
   │
   ▼ ① 點名：哪一條？帶數值
   │    ✓「Breusch-Pagan LM=41.2, p=1.4e-9；殘差圖漏斗形，前後 20% 分位的殘差 SD 差 3.8 倍」
   │    ✗「殘差不符合假設」
   │
   ▼ ② 轉換（ref 06 §一 的順位表）
   │    └─ 有效 → 回 §四 重跑全套診斷。轉換後要重畫殘差圖，不可沿用舊圖
   │
   ▼ ③ 轉換無效 → 換模型族（§一）：計數走 NB、含 0 金額走 Tweedie、比例走 Binomial
   │    └─ 這一步是「換對的族」，不算降級。降級是下面兩步
   │
   ▼ ④ 穩健標準誤：cov_type="HC3"（異質變異）／"cluster"（同顧客多筆）／Newey-West（自相關）
   │    ✅ 保住：係數解讀、效果量、單位效果
   │    ❌ 放棄：找到正確函數形式。預測區間仍不可信
   │
   ▼ ⑤ 樹模型（RandomForest / GBDT）
   │    ✅ 保住：預測能力、變數重要性排序
   │    ❌ 放棄：**係數解讀全部消失** —— 見下方紅字
   │
   ▼ ⑥ 退到底：敘述統計 + 明說「本節無法主張 X」
        章節保留，不准整章刪掉（18-E11）
```

**第 ⑤ 步必須在報告寫清楚的一句話**：樹模型的「變數重要性」**不是效果量，沒有方向、沒有單位、沒有信賴區間**。它能回答「哪些變數對預測有用」，**不能回答「多花一萬元廣告會多幾筆訂單」**。M11 的 sizing 與損益兩平反應率需要的是後者 —— 所以降到第 ⑤ 步時，**M11 的建議只能寫成排序型（Top-N 名單），不能寫成金額型**。要拿回單位效果就得走 SHAP 的部分依賴（M9，ref 12），而那是模型內的解釋，不是母體參數，證據等級仍只到「預測」（00 §1.5）。

`DHARMa` 沒有 Python 對應品，**GLM 的殘差診斷是這次 R→Python 遷移的真實損失**。替代做法：deviance residual vs linear predictor 的散佈圖 + binned residual plot，並接受這一塊比 R 弱。這件事要寫進報告的方法論限制，不要假裝診斷做完了。

下表的「失效證據」欄是**寫法示範**，數值為說明用的典型量級【推導，待驗證】，實際填的必須是這批資料真的跑出來的數字（00 §2.2：升級／降級的觸發必須點名）。程式碼見 `templates/迴歸建模_程式範本.py` 的 `robust_refit()`。

| 原方法 | 失效證據（要帶數值） | 降級到 | 結論因此弱在哪 |
|---|---|---|---|
| OLS（營收 ~ 通路投入） | BP $p=1.4\times10^{-9}$，殘差 SD 前後 20% 差 3.8 倍 | log(Y) + OLS | 係數變成半彈性，**預測值不可直接 exp**（ref 06 §二） |
| Poisson（訂單數 ~ 通路） | $\hat\psi = 4.79$（$s^2=11.5$ vs $\bar x=2.4$） | Negative Binomial | 無實質損失，這是修正不是降級 |
| OLS（客單價 ~ 群別） | Levene $p=0.003$；群 3（$n=47$）變異數為群 1 的 11.4 倍 | Welch ANOVA + Games-Howell（**不可退 KW**：變異數比 11.4 已破 KW 的形狀假設，見 05 §1.2）（BH 校正） | 只能主張中位數排序，**不能報「平均差 X 元」** |

| 全部失效 | 承上，前五列的證據已足夠 | 敘述統計對照表 | 本節無法主張因果或單位效果，章節保留（18-E11） |
