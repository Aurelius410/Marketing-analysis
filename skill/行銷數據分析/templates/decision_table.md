# 決策表範本（M11 §八）

一群一張，固定三列。規格與樣本量規則見 `references/14_決策轉譯.md` §八。

## 複製後要改哪幾個地方才能用

1. **檔名必改**：複製到 `<專案>/交付物/` 時要改名成 **`decision_tables.md`（複數 s）**。
   `verify_outputs.py` 的 M01 檢查寫死的是這個檔名，照原名 `decision_table.md` 複製過去
   會被判「缺少 交付物/decision_tables.md」→ error → 不得輸出。
   ```bash
   cp templates/decision_table.md <專案>/交付物/decision_tables.md
   ```
2. **刪掉本檔的說明段**：交付物只留決策表本身。下面「填好的樣本」那一段（飄忽鼠）是
   體例示範，不是你的資料，留在交付物裡就是把別人的結論當自己的交。
3. **一群一張，逐張填**：`{}` 包起來的每一格都要換成這批資料真的跑出來的內容。
4. **`→ rec_id` 必改**：要對得回 `交付物/sizing.csv` 的 `rec_id` 欄，對不上等於建議沒有
   成本與損益兩平的支撐。
5. **第 (3) 條必須是「某檢定 → 具體行動」**：檢定名稱、統計結果、行動三段都要有；
   群太小不敢下這條就整條拿掉並補承認／降級／轉向那段，不要留空殼。

同一批交付物還需要 `insights.md`、`decision_summary.md`、`sizing.csv`、
`calibration_log.csv`、`excluded_options.csv` 與至少一份 `audience_*.csv`，
缺一即 M11 不得標記完成（14 §九）。

```
                        {分群名（可用動物化命名 + 一句話點評）}
──────────────────────────────────────────────────────────────
指標特性       | {R/F/M/CAI/CRI 的高低組合} → {一句話定性}
消費者輪廓描述 | {年齡區間}歲{地區}{性別}為主，可能{推測性的心理特徵}
決策建議       | (1) {行動}：{具體手段與優惠數字}。            → rec_id
              | (2) {行動}：{具體手段與優惠數字}。            → rec_id
              | (3) {某檢定}顯示{統計結果}，{因此的具體行動}。 → rec_id ← 必備
```

## 填好的樣本（沿用原報告逐字體例）

```
                        飄忽鼠（時而出沒，金額小，滑個兩下就跑掉。）
──────────────────────────────────────────────────────────────
指標特性       | 購買頻率中高、客單價中上；高 CAI、較高 CRI → 活躍但不穩定
消費者輪廓描述 | 31–40 歲北部男性為主，可能較熱衷新品且對促銷敏感
決策建議       | (1) 忠誠度動態紅利與 VIP 專屬優惠，平滑波動。          → R4
              | (2) 個性化耗材提醒，引導定期補貨，提升穩定度。          → R5
              | (3) F-Test 與 LSD 顯示北區表現顯著優於南區（全部三獲利
                    指標），可鎖定北區導入差異化促銷。                  → R6
```

樣本太小的版本（狂刷豹，n=5）：只給 (1)(2)，**不給第 (3) 條**，並在表下加一段
「承認（僅 5 人、結構單一）→ 降級（參考價值相對有限）→ 轉向（建議聚焦規模較大的兩群）」。
表格與群一律保留，只降低宣稱強度。

## 三列各自的紀律（速查）

| 列 | 只能寫什麼 | 不准寫什麼 |
|---|---|---|
| 指標特性 | 分群輸入變數的高低組合（白名單見 18-E2）+ 一句定性 | 人口變數；四張表共用同一串描述 |
| 消費者輪廓描述 | 卡方章的結果；推測加「可能較…」「一定程度上，可以推斷…」 | 貶義或獵奇的人群描述（學結構，不學修辭） |
| 決策建議 | (1)(2) 具體手段 + 優惠數字 + 通路；(3) 檢定 → 行動 | 空泛策略（18-E20）；全報告至少一處明說「應停止做什麼」（18-E21） |
