# 群命名體例與決策表範本（M6）

規格與判定規則見 `references/07_標籤與分群.md` §九。這份是可直接複製填空的範本。

---

## 一、四件套（缺一不可）

1. **動物名**（兩到三字，可在會議上叫出來）
2. **High / Medium / Low 五維表**（先數值化，再接文字）
3. **文字描述**（2–4 句，**說行為不說人口**）
4. **一句話點評**（口語、有畫面感）

---

## 二、包子原報告的實際輸出（k=4，n=150，3C 賣場）

出處：`00_source_archive/gdrive/own/01_包子自己的報告與作業.md` §3.3 表 7.2【實測】

| 分群名稱 | 飄忽鼠 | 冬眠熊 | 沉穩牛 | 狂刷豹 |
|---|---|---|---|---|
| R 指標 | High | High | High | High |
| F 指標 | Low | Low | Low | **High** |
| M 指標 | Low | Low | **High** | **High** |
| CRI 指標 | Low | Medium | **High** | Low |
| CAI 指標 | High | Low | Medium | Medium |
| 佔比 | 46.3% | 43.6% | 6.7% | **3.4%（5 人，未過可執行性檢驗）** |

一句話點評實際樣本：

> 飄忽鼠：「時而出沒，金額小，滑個兩下就跑掉。」
> 沉穩牛：「步調慢、出手穩，一刷就是高單價。」
> 狂刷豹：「刷得快又多，活躍衝刺但步伐飄忽。」

**破格只發生在命名，不發生在論述。** 章名一律中性（「集群分析」「資料概述」），只有群名可以有人味。

---

## 三、High / Med / Low 的切法（differential labeling）

**不要用群內絕對值切**，要用相對全體的 index，否則會踩教材的「Computer 陷阱」（五個群的 top feature 都是「都會區」，因為那是整體樣本的共同特徵）。

$$\text{index}_{k,j}=\frac{\bar x_{k,j}}{\bar x_{\cdot,j}}\times100$$

| index | 標記 |
|---|---|
| ≥ 120 | **High** |
| 80 – 120 | Medium |
| ≤ 80 | **Low** |

【推導，待驗證；相當於 $z\gtrsim\pm0.5$ 的量級】

命名只准用 index 明顯偏離 100 的維度。**五維全部落在 80–120 的群沒有特徵，該被合併**（見 07 §5.3 第 ③ 步）。

## 四、命名反面清單

```
✗ 群 1 / 群 A / Cluster 3          —— 沒有資訊
✗ 高價值客 / 潛力客 / 一般客        —— 只有價值軸，猜不出行為
✗ 年輕族群 / 都會白領 / 主婦族       —— 人口描述，違反 18-E2 的精神
✗ VIP / 鑽石 / 白金                —— 與既有會員等級撞名，讀者混淆兩套系統
✓ 飄忽鼠 / 冬眠熊 / 沉穩牛 / 狂刷豹  —— 行為 + 節奏 + 金額都在名字裡
```

## 五、命名驗證：盲測三題

把五維表遮起來，只給群名，問一位沒參與分析的同事：

| 盲測題 | 通過標準 |
|---|---|
| 「這群人多久買一次？」 | 答案方向與 F/R 的 High/Low 一致 |
| 「這群人單次買多貴？」 | 答案方向與 M 一致 |
| 「這群人最近在不在買？」 | 答案方向與 R/CAI 一致 |

答對 ≥ 2 題 → 通過。答對 ≤ 1 題要先分辨是**命名壞**（五維有明顯特徵但名字抽象 → 重新命名，用 index 最極端的兩維造名）還是**群壞**（五維全是 Medium → 回 07 §5.3 第 ③ 步合併）。

## 六、決策表範本（每群一張）

**建議固定 3 條，第 (3) 條必為統計結果直翻行動**（「某某檢定顯示 X，因此建議 Y」）。那一條是統計章存在的唯一理由，也是讓管理者相信前面 20 頁檢定不是白做的唯一證據。

```markdown
### 表 11.x：<群名> 的行銷決策建議

| 項目 | 內容 |
|---|---|
| **指標特性** | R <H/M/L>、F <H/M/L>、M <H/M/L>、CRI <H/M/L>、CAI <H/M/L>；人數 <n>（<pct>%） |
| **消費者輪廓描述** | <2–4 句，說行為不說人口。含 index 偏離最大的兩個維度> |
| **一句話點評** | <口語、有畫面感> |
| **決策建議 (1)** | <通路 + 具體優惠數字 + 目標客群編號> |
| **決策建議 (2)** | <同上> |
| **決策建議 (3)** | **<某某檢定顯示 X（統計量、p、效果量），因此建議 Y>** |
| **證據等級** | 相關／預測／準實驗／實驗（見 00_通則 §1.5，措辭白名單要對得上） |
| **損益兩平反應率** | <%>（sizing 見 14_決策轉譯.md） |
```

每條建議必須含：**統計依據（帶 p 值／係數）+ 具體通路 + 具體優惠數字 + 目標客群編號**（18-E20）。報告至少要有一條「該停止做什麼」的負面建議（18-E21）。

## 七、樣本太小跑不出檢定時的三段式處置

出處：包子原報告狂刷豹（5 人）的實際做法【實測】

```
① 承認：「本群僅 5 人、結構單一」
② 降級：「參考價值相對有限」
③ 轉向：「建議聚焦飄忽鼠與冬眠熊」

決策建議從 3 條降為 2 條（少掉的正是第 (3) 條統計那條）
但 —— 不刪章節、不刪表格、只降低宣稱強度（18-E11）
空格填法：無樣本填 `—`、算不出來填 `N/A`（00_通則 §四），從不留空白
```
