### 0.2 【評註】這門課的「行銷數據分析動作清單」（本檔最核心的萃取結果）

從八次作業 + 期末報告的必備章節反推，這門課認定「做行銷數據分析」必須會的動作，依執行順序：

1. **資料庫盤點與型態辨識** — 分辨靜態基本檔／動態購買檔／編碼檔（交易日期編碼 + 產品特性編碼）三種型態。
2. **衡量尺度判定** — Nominal / Ordinal / Interval / Ratio，並知道哪種最好不要用。
3. **欄位工程（feature engineering with 行銷理論支撐）** — 為特定產業額外創造編碼欄位（如「連假與否」0/1），且必須說明理由。
4. **去重與粒度統一** — 顧客ID + 日期串接成唯一鍵，把「同一顧客同一天多筆」壓成一筆（以天為分析單位）。
5. **RFM 三指標計算** — 三種做法：土法煉鋼轉軸法、樞紐分析表法、Excel 函數法。
6. **權重設計與情境化** — Bob Stone 法自訂權重規則，且必須解釋為何這樣訂（產業特性）。
7. **無母數分位切分** — 五等分法（PERCENTRANK + 五級對照）。
8. **多方法排名交叉比較** — 原版 Bob Stone / 自訂 Bob Stone / 五等分法三者排名差異，取前20~30% 與後20~30% 樣本做特徵描述。
9. **時間間隔指標（interpurchase time）與加權** — 近期交易權重更高，算 WMLE。
10. **活躍性指標 CAI** — MLE 與 WMLE 的相對差距百分比。
11. **指標分佈的機率化** — 用常態累積分佈把 CAI 轉成累積相對次數，畫成分佈圖。
12. **收縮估計（貝氏平均）** — 個體均數往區隔總體均數收縮，處理小樣本個體不穩定。
13. **CRI 指標** — 顧客關係／一致性指標（作業要求算，但範本未在本批檔案中）。
14. **購物籃分析（對稱路線）** — 次數矩陣 → dummy 0/1 → 相關係數矩陣 → 排序取 Top20。
15. **購物籃分析（有方向路線）** — 「下次購買產品」欄位 → 轉移次數矩陣 → 條件機率矩陣 → Top20。
16. **降維（因素分析／主成分）** — 旋轉成份矩陣、因素分數、命名與解讀。
17. **集群分析** — K-means / 2-step / Ward，用前面自建的 RFM、CAI、CRI 等新指標當輸入變數。
18. **分群後輪廓描述的統計檢定套組** — 卡方適配度檢定、卡方獨立性檢定（人口統計變數）、F 檢定 / 單因子 ANOVA（獲利指標）、事後檢定，事後檢定跑不出來時退回手動獨立樣本 T 檢定或敘述統計。
19. **商業轉譯** — 每一章節末尾一段小結；報告最後給管理者的行銷決策建議。
20. **文書工程** — 封面、摘要、目錄、頁碼、章節大小標、表格重製（不得直貼 SPSS 輸出）、跨頁表頭重標。

### 3.9 【原文】方法三：Excel 函數 RFM 法（`函數RFM法(含公式)` 逐格公式）

### 3.10 【原文】`Bob Stone rule` 工作表（權重規則設計表，逐格）

| 構面 | 給分機制 | 權重 | 原因 |
|---|---|---|---|
| 最近一次購買日 Recency(R) | 最近30天內為5分<br>最近31~60天為4分<br>最近61~90天為3分<br>最近91~120天為2分<br>最近121~150天為1分<br>最近151天以上為0分 | 低 | 3C賣場的產業性質本身屬於人均購買次數較低、單次購買金額較高之產業。<br>若購買次數過低，可能代表顧客對於賣場之忠誠度不高，因此購買次數為RFM分析中最重要之權重；<br>次者為購買金額，因購買金額高低係決定3C賣場利潤的主因；<br>最不重視最近一次購買日，因最近一次購買日較可能因消費者週期較長而有所不同。 |

### 3.11 【原文】`RFM轉Bob Stone法` 工作表（自訂 Bob Stone 計分實作，逐格公式）

欄位：`客戶no. | Recency | Frequency | Monetary Value | R(Recency) | F(Frequency) | M(Monetary Value) | RFM Score | RANK`

```excel
' E2 — R 分數（依 Bob Stone rule 的 30 天級距）
=_xlfn.IFS(B2<=30,5,B2<=60,4,B2<=90,3,B2<=120,2,B2<=150,1,B2>150,0)

' F2 — F 分數
=ROUND(C2*4,0)

' G2 — M 分數（0.25% 後取整，上限 9）
=MIN(INT(D2*0.0025),9)

' H2 — RFM 總分
=E2+F2+G2

' I2 — 排名
=RANK(H2,H:H)
```

範例列（客戶 89）：`Recency=19, Frequency=85, Monetary Value=150681`
→ R=5、F=ROUND(85×4)=340、M=MIN(INT(150681×0.0025),9)=MIN(376,9)=9、總分=354。

**【評註】三處實作與規則表不一致，抄範本時要注意：**
1. 規則表 F 寫「購買次數/2」，實作卻是 `C2*4`（乘 4）。
2. 規則表 M 寫「**平均**購買金額×0.25%，最高**10**分」，實作卻是用**總**金額 `D2`（來自 SUMIF 的加總）且上限為 **9**。
3. 實作的 F 分數（340）遠大於 R（5）與 M（9），實際上 F 幾乎完全支配總分排名。這正好呼應 §3.13 `分析比較` 工作表原文的觀察：「R score、M score 的皆有上限值（24與9），造成唯一可以影響排名的僅有 F score，因為 F score 計算方式為次數*4，所以消費頻率在 Bob Stone 法中扮演權重較大的角色」。**「上限造成的隱性權重」是這份範本最重要的方法論教訓。**

### 4.9 【原文】Step 5：WMLE 與 CAI 公式（核心）

`Step 5` 欄位：`客戶ID | MLE | 加權加總 | 加權值加總 | WMLE | CAI`

```excel
' E2 — WMLE = 加權值加總 ÷ 加權加總
=D2/C2

' F2 — CAI = (MLE − WMLE) / MLE × 100
=((B2-E2)/B2)*100
```

註解（原檔 H3、H4 儲存格）：

> H3：計算 WMLE
> H4：計算 CAI

以 LaTeX 表示：

$$\text{MLE}_i = \frac{1}{n_i}\sum_{j=1}^{n_i} \text{int}_{ij}
\qquad
\text{WMLE}_i = \frac{\sum_{j=1}^{n_i} w_{ij} \cdot \text{int}_{ij}}{\sum_{j=1}^{n_i} w_{ij}}
= \frac{\sum_{j=1}^{n_i} j \cdot \text{int}_{ij}}{\sum_{j=1}^{n_i} j}$$

$$\boxed{\ \text{CAI}_i = \frac{\text{MLE}_i - \text{WMLE}_i}{\text{MLE}_i} \times 100\ }$$

抽樣列驗算（客戶 89）：MLE = 10.2794、加權加總 = 2346、加權值加總 = 27145
→ WMLE = 27145 / 2346 = 11.5707
→ CAI = (10.2794 − 11.5707) / 10.2794 × 100 = **−12.56**

**【評註】CAI 的解讀方向（極重要，容易搞反）：**
- **CAI > 0** ⟺ WMLE < MLE ⟺ 近期的購買間隔比全期平均**更短** ⟺ 購買節奏在**加快** ⟺ **越來越活躍**。
- **CAI < 0** ⟺ 近期間隔變長 ⟺ 節奏**變慢** ⟺ **走向流失**。
- CAI ≈ 0 ⟺ 節奏穩定。
- 理論上界為 100（WMLE → 0），下界無界（WMLE 可遠大於 MLE），因此分佈**左偏長尾**。實測 CAI 範圍約 −43.7 到 +54.6（見 §4.10）。

**從題目順序可推得的四步計算鏈**（以下為推論，非原文）：

1. **個體層**：每位顧客 $i$ 的平均購買金額 $\bar{x}_i$ 與變異數 $s_i^2$。
2. **總體層**：每個區隔（segment）的平均購買金額 $\mu$ 與變異數 $\tau^2$（區隔間變異）。
3. **貝氏收縮（Bayesian shrinkage / James–Stein 型）**：個體均數往總體均數收縮，收縮量取決於個體樣本數 $n_i$ 與兩層變異的比例。標準形式為

   直覺：交易筆數少的顧客，其個體均數不可信，往區隔均數拉；交易筆數多的顧客，維持自己的均數。
4. **CRI 指標**：題目未定義。從課程脈絡（本單元講 CLV 與遷徙路徑）與 CAI 的命名慣例（Customer Activity Index）推測是 **Customer Relationship / Retention Index** 一類的指標，做法應與 CAI 平行（以某個基準量與加權量的相對差距 × 100）。**HW8 原文明確把 CRI 與 RFM、CAI 並列為「過去幾周我們所建立的新指標」**，所以 CRI 確實是本課自建指標之一。

**【評註】重要警告：分母是絕對參照 `$Q$19`，也就是整張矩陣的「總計」單一格。** 這樣算出來的是**聯合機率** $P(A \cap B)$，而不是評分標準要求的**條件機率** $P(B \mid A)$。理論上正確的做法應該是除以**該列的列總計**：

$$P(B \mid A) = \frac{N(A \to B)}{\sum_{B'} N(A \to B')} = \frac{N(A \to B)}{N(A)}$$

由於 Top-20 只看排序，除以同一個常數不改變全表排序，所以這個範本仍能得到「一樣的 Top20」；但數值本身的解讀（「買了 A 之後有多大機率買 B」）是錯的，且**有方向性會消失**（$P(A\cap B) = P(B \cap A)$ 對稱）。做新 Skill 時要用列總計當分母。

| 數學本質 | 兩者變動趨勢的線性同步性 | 已知 A 發生下，B 發生的條件機率 |
| 方向性 | 無方向性（對稱）<br>A->B 的數值與 B->A 完全相同 | 有方向性（非對稱）<br>A->B 的機率不等於 B->A |
| 商業解讀 | 找出哪些產品屬於「同一個消費生活圈」 | 找出「買了 A 之後，有多大機率會買 B」 |
| 數據敏感度 | 容易放大低頻率但趨勢一致的群組 | 腳踏實地，反映真實交易量基數與信心度 |
| 核心商業應用 | 產品促銷與包裝設計<br>面向整體的行銷規劃 | 動態即時推薦系統<br>面向個體、有時間先後的系統觸發 |
| 實務應用舉例 | 企劃「時尚美麗週」：買精品送藥妝抵用券 | 系統偵測到交通消費，秒推量販店優惠 |
| 對推薦系統的價值 | 「大方向參考」：知道哪些可以綁在一起。 | 「直接執行劇本」：知道順序，不怕推錯時間。 |

> **結論亮點（B17 儲存格原文）**
> 「相關係數分析」適合用於靜態的策略包裝與異業結盟，幫助行銷人員建立大方向促銷組合；而「條件機率分析」因具備方向性，能精確捕捉消費行為的先後順序，因此是打造自動化即時推薦系統 (如 App 推播、結帳交叉銷售) 最精準且不可或缺的演算依據。

**【評註】** 這張七維度對照表是**兩法比較論述的最佳模板**，可直接搬進新 Skill（見 §10.5）。

> A：不錯，是一份完全可以拿上檯面的商業報告，該有的東西都有，面面俱到。
>
> A-：東西是不缺，但每一項就只有簡單的寫一點點內容不夠豐富，或是排版視覺等因素，反正，簡言之，就是讓人然覺得還可以，但感覺就是還未到A的程度。
>
> B範圍之內上下調整 (B-至B+)：看上去還OK，但就是有缺一些東西，不夠完整。
>
> C範圍之內上下調整 (C-至C+)：差強人意，很明顯是趕工出來，用來應付期末報告的作品。整體的製作上，品質非常低劣。
>
> F：沒繳或者繳交的內容一蹋糊塗，完全不知所云，或明顯抄襲別人的報告。

### 9.5 【原文】對 AI 使用的立場

> 最後，由於我們也已經進入AI時代了，很多同學開始都用AI來作做業，我們也沒有反對使用AI寫報告，我們在乎的是在有AI的輔助下，大家的報告是否更為完整，更有深度，可以說服看報告的人（主管或管理者）買單您的說法。

**【評註】** 這一段對新 Skill 的定位非常關鍵：**課程明確允許用 AI，但評判標準轉移到「完整度、深度、說服力」**。所以 Skill 的價值不在於「代寫」，而在於「保證不缺項 + 把每個指標的商業意義講到位」。

### 10.4 公式庫

#### 10.4.1 RFM 三指標 [原文依據 §3.9]

$$R_i = D_{\text{base}} - \max_{t \in T_i}(\text{date}_t), \qquad F_i = |T_i|, \qquad M_i = \sum_{t \in T_i}\text{amount}_t$$

```excel
=$F$2-E2                                                    ' Recency
=COUNTIF(交易檔!客戶ID欄,A2)                                  ' Frequency
=SUMIF(交易檔!客戶ID欄, A2, 交易檔!金額欄)                     ' Monetary
=(MAX(IF((交易檔!客戶ID欄=A2),交易檔!日期欄,FALSE)))            ' 最後消費日（陣列公式）
```

#### 10.4.2 五等分法計分 [原文依據 §3.12]

```excel
=PERCENTRANK.INC(B:B,B2)                                                     ' 分位
=IF(E2<=0.2,5,IF(E2<=0.4,4,IF(E2<=0.6,3,IF(E2<0.8,2,1))))                    ' R：越小越高分
=IF(F2>=0.8,5,IF(F2>=0.6,4,IF(F2>=0.4,3,IF(F2>0.2,2,1))))                    ' F/M：越大越高分
```
（原範本傳回文字 `"5"`；此處已改為數值。）

#### 10.4.3 原版 Bob Stone 計分 [推導自 §3.13 實值 + 原文 §3.11 公式]

$$R\text{-score} = \begin{cases}24 & 0 \le R \le 90 \\ 12 & 91 \le R \le 180 \\ 6 & 181 \le R \le 270 \\ 3 & 271 \le R \le 360 \\ 0 & R > 360\end{cases}
\qquad F\text{-score} = 4F \qquad M\text{-score} = \min(\lfloor c \cdot M \rfloor,\ 9)$$

```excel
=C3*4                          ' F-score（原文公式）
=INT(2^(4-INT(B3/90)))         ' 自訂 R-score 變體（原文公式，值域 1~16）
=MIN(INT(D2*0.0025),9)         ' M-score（原文公式，c = 0.25%）
```

#### 10.4.4 CAI 活躍性指標（完整六步）[原文依據 §4.4–§4.9]

$$\text{int}_{ij} = t_{i,j+1} - t_{i,j}, \quad w_{ij} = j, \quad
\text{MLE}_i = \frac{1}{n_i}\sum_j \text{int}_{ij}, \quad
\text{WMLE}_i = \frac{\sum_j j \cdot \text{int}_{ij}}{\sum_j j}$$

$$\boxed{\ \text{CAI}_i = \frac{\text{MLE}_i - \text{WMLE}_i}{\text{MLE}_i} \times 100\ }$$

```excel
' Step 前置：合併鍵，用於「移除重複項」
=C2&D2

' Step 2：interpurchase time（下一列減本列；跨客戶填 9999 待刪）
=IF(A3=A2,B3-B2,9999)

' Step 3：權重 = 交易序位
=IF(A3=A2,1+D2,1)
=C2*D2                         ' int × weight

' Step 4：樞紐分析表 — 列標籤=客戶ID，值 = 平均值(int)、加總(weight)、加總(int×weight)

' Step 5
=D2/C2                         ' WMLE = 加權值加總 / 加權加總
=((B2-E2)/B2)*100              ' CAI

' 分佈機率化
=NORM.DIST(x, mean, sd, 1)     ' 範本用 mean=0, sd=15
```

**執行順序（漏一步就是「跳步驟」，評分標準明列會降等）**：
1. 只留 `客戶ID` + `日期` 兩欄（Step 0）。
2. 串接 `客戶ID & 日期` → 移除重複項 → **同客戶同日壓成一筆（以天為分析單位）**（Step 1）。
3. **依客戶ID + 日期排序**（否則 offset 公式全錯）。
4. 算 `int`（Step 2）。
5. **刪除每位客戶的最後一筆（int = 9999 的列）**（Step 2 註解）。
6. 算 `weight`（序位）與 `int × weight`（Step 3）。
7. 樞紐三個彙總量（Step 4）。
8. 算 WMLE、CAI（Step 5）。
9. 常態累積分佈 → 切「非常活躍群 / 非常不活躍群」→ 用人口統計欄位比較兩群特徵。

**CAI 解讀方向**：CAI > 0 = 節奏加快 = 越來越活躍；CAI < 0 = 節奏變慢 = 走向流失。

### 10.5 範本：兩種購物籃分析方法的七維度比較表 [原文依據 §6.6.3]

| 比較維度 | 相關係數矩陣 | 條件機率矩陣 |
|---|---|---|
| 數學本質 | 兩者變動趨勢的線性同步性 | 已知 A 發生下，B 發生的條件機率 |
| 方向性 | 無方向性（對稱），A→B = B→A | 有方向性（非對稱），A→B ≠ B→A |
| 商業解讀 | 哪些產品屬於「同一個消費生活圈」 | 「買了 A 之後，有多大機率會買 B」 |
| 數據敏感度 | 容易放大低頻率但趨勢一致的群組 | 反映真實交易量基數與信心度 |
| 核心商業應用 | 產品促銷與包裝設計；面向整體的行銷規劃 | 動態即時推薦系統；面向個體、有時間先後的系統觸發 |
| 實務應用舉例 | 企劃「時尚美麗週」：買精品送藥妝抵用券 | 系統偵測到交通消費，秒推量販店優惠 |
| 對推薦系統的價值 | 大方向參考：知道哪些可以綁在一起 | 直接執行劇本：知道順序，不怕推錯時間 |

**加上第三法（因素分析）的比較維度** [原文依據 §7.2、§7.3.3]：

| 維度 | 相關係數法 | 因素分析法 |
|---|---|---|
| 籃子數 vs 籃子內品項數 | 籃子多，每籃只有 2 個商品 | 籃子少，每籃可供決策的品項多 |
| 優勢 | 直觀具體，可直接落地交叉銷售搭售 | 降維後看見整體商業結構，能描繪消費者輪廓（如「高消費享樂型」） |
| 缺點 | 缺乏宏觀視角、變數多時組合爆炸、無法解釋潛在動機 | 成分命名與解讀主觀、降維遺失細節、難轉成單一商品推薦規則 |
| 額外產出 | 無 | **因素分數** —— 可得知每一位消費者對每一個購物籃的偏好強度 |
| 整合策略 | 先用因素分析做大方向輪廓分群，再對各特定客群用相關係數分析找具體搭售組合 | |
